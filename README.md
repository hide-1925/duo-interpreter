# Duo Interpreter

対面での会話を、その場で双方向に通訳するWebアプリです。HTML 1ファイルだけで動きます。

画面を上下（または左右）に分割して、**自分side（A）** と **相手side（B）** にそれぞれの言語で会話ログを表示します。スマホをテーブルに置いて相手と挟んで使う、PCの画面を一緒に覗き込む、といった使い方を想定しています。

**👉 [https://hide-1925.github.io/duo-interpreter/](https://hide-1925.github.io/duo-interpreter/)**

インストール不要・アカウント登録不要。**APIキーなしの完全無料でも動きます。**

## 3分ではじめる

1. 上のURLをブラウザで開く
2. **⚙** → 「翻訳・API」タブ
   - 翻訳プロバイダ = **🆓 無料モード**
3. 「音声」タブ
   - 音声認識 = **🆓 ブラウザ内蔵 Web Speech API**
   - 読み上げ = **🆓 ブラウザ内蔵音声**
4. 閉じて、操作エリアで **A / B の言語**を選ぶ（既定は A=日本語、B=English）
5. **● 開始** を押してマイクを許可 → 話す

これでAPIキーなし・課金なしで通訳が動きます。

### スマホは「ホーム画面に追加」がおすすめ

共有ボタン → 「ホーム画面に追加」で全画面表示になり、アドレスバーの分だけ会話ログが広く使えます。PCはブックマークが便利です。

> **注意：** ブラウザ内蔵の音声認識（無料）は Chrome / Edge 系のエンジンが前提です。iPhone / iPad の Safari では動かないことがあります。その場合は音声認識を OpenAI などのAPIに切り替えるか、PCのChromeでお使いください。

## できること

### 🎤 音声を聞き取って、その場で翻訳

話した内容を認識して、もう片方の言語に翻訳し、両方のパネルに表示します。翻訳結果は音声で読み上げることもできます。

聞き取る言語の切り替えは **手動**（ボタンかパネルのタップ）と **AUTO**（A/B交互に自動で切り替え）が選べます。無料モード（ブラウザ内蔵の音声認識）では、認識エンジンが1言語ずつしか扱えない都合でAUTOは使えません。手動固定になります。

### ⌨ キーボード入力にも対応（言語は自動判定）

操作エリアの **⌨** ボタンで入力欄が開きます。打った文章がA・Bどちらの言語かを自動で判定して、もう片方の言語に翻訳します。**言語を選ぶ操作は不要です。**

- 判定は端末内で完結（文字種＋その言語らしい単語・アクセント記号で採点）。通信は発生しません
- ラテン文字同士（英↔独、西↔葡など）で判定が割れたときだけ、Google翻訳の言語判定（無料・キー不要）に問い合わせます
- 判定を使いたくないときは、入力欄左の「話者」ボタンで **A固定 / B固定** に切り替えられます
- Enterで送信、Shift+Enterで改行。日本語入力の変換確定Enterでは送信されません

騒がしい場所、固有名詞や数字を正確に伝えたいとき、音声認識がうまくいかないときの保険として使えます。

### 📷 カメラで文字を翻訳

**📷** ボタンでカメラが起動します。画面をタップした瞬間の1コマだけを読み取り、写っている文字をA話者の言語に翻訳します。看板・メニュー・書類などに。

- **写真は端末に一切保存されません**（メモリ上の1コマをそのまま画像認識に送るだけ）
- 結果は「＋ 会話ログに追加」で会話ログに残せます
- 画像を読めるAIモデルが必要なので、無料モードでは使えません

### 🔊 読み上げ

翻訳結果を音声で読み上げます。「相手(B)の発言だけ」「両方」などを選べます。

各発言の吹き出しにある **🔊** ボタンを押せば、読み上げ設定がOFFでもその1文だけを読み上げられます（そのパネルに表示されている文章をそのまま読みます）。

#### 話者A / B で声を分ける

読み上げ対象を「両方」にすると、どちらの発言を聞いているのか分からなくなりがちです。そこで **自分(A) と 相手(B) で別の声**を設定できます。⚙ → 音声 に、選んだエンジンごとの2列（左＝自分(A) / 右＝相手(B)）が出ます。

| エンジン | A/B別の声 |
|---|---|
| OpenAI 音声 | 7種類の声から個別に選択 |
| 🗣 ElevenLabs | 声を個別に選択（自分の声も含む） |
| 🎙 Aivis Cloud API | モデルUUIDを個別に指定 |
| 🖥 ローカルエンジン | 話者を個別に選択 |
| 🫛 VOICEVOX WEB版 | 話者を個別に選択 |
| 🆓 ブラウザ内蔵音声 | 設定なし（言語ごとに自動で選ばれます） |

- 読み上げ対象が「相手(B)だけ」「自分(A)だけ」のときは、使わない側の列は自動で隠れます
- Aivis Cloud とローカルエンジンは、自分(A)側を空にしておくと**相手(B)と同じ声**になります
- 日本語専用エンジン（Aivis / ローカル / VOICEVOX）は、日本語で読む発言だけがその声になります。もう一方の言語はブラウザ内蔵音声です

### 読み上げをZoom/Teamsのマイクとして流す

⚙ → 音声 の「**読み上げの出力先デバイス**」で、読み上げを鳴らすスピーカーを選べます。ここに**仮想オーディオケーブル**を指定して、会議アプリ側でそれをマイクとして選ぶと、訳文が相手に音声で届きます。

| OS | ソフト | 備考 |
|---|---|---|
| Windows | VB-CABLE | 単純な1本のケーブル |
| Windows | VoiceMeeter | 自分の生声とTTSを混ぜられる |
| macOS | BlackHole | 単純な1本のケーブル |
| macOS | Loopback（有料） | 混合・分岐ができる |

制約：

- **ブラウザ内蔵音声には効きません。** `speechSynthesis` は仕様上、既定のスピーカーからしか鳴らせないためです。OpenAI音声とVOICEVOXでご利用ください
- 対応ブラウザは Chrome / Edge のデスクトップ版が中心です。Safari・iPhone・iPadでは選択肢が出ません
- ケーブルをマイクにすると**自分の生声は相手に届きません**。両方流すには VoiceMeeter / Loopback での合成が必要です
- 会議音声を「タブ音声」で認識させている場合、読み上げが会議に戻ってループしないようご注意ください
- デバイス名が出ないときは、一度「● 開始」でマイクを許可してから 🔄 更新 を押してください（ブラウザの仕様でマイク許可後にデバイス名が読めるようになります）

### 🗣 自分の声で読み上げる（ElevenLabs）

読み上げに **🗣 ElevenLabs** を選ぶと、**自分の声で日本語も英語も読み上げ**られます。

1. [ElevenLabs の Voice Lab](https://elevenlabs.io/app/voice-lab) で **Instant Voice Cloning** を選ぶ
2. **2分未満**の自分の録音をアップロード（学習の待ち時間はありません）
3. [API Keys](https://elevenlabs.io/app/settings/api-keys) でキーを取得し、⚙ → 音声 → ElevenLabs に貼る
4. 「🔄 声を取得」を押すと、作った声が一覧の**先頭**に出てきます（自分でクローンした声を上に並べています）

| モデル | 特徴 |
|---|---|
| **Flash v2.5** | 公称75ms級・32言語。**同時通訳ならこれ** |
| Multilingual v2 | 高品質・29言語。そのぶん待ちが伸びます |
| Turbo v2.5 / Flash v2 | 旧世代・英語のみ |

**日本語専用エンジンとの一番の違いは、言語を選ばないこと**です。A席の英訳もB席の和訳も同じ自分の声で読めるので、両方を1つの声に揃えられます。

> **⚠ 声の複製について**
> 本人の同意なく他人の声を複製することは、ElevenLabs の規約でも法令でも認められません。自分の声、または明確な許諾を得た声だけをお使いください。

### 日本語の読み上げに別のエンジンを使う

日本語専用の音声合成エンジンを3つ選べます。いずれも**日本語の読み上げだけ**がその声になり、他の言語はブラウザ内蔵音声で読み上げます。キー未設定・接続失敗・エラー応答のときも、自動でブラウザ内蔵音声に切り替わるので会話は止まりません。

| | 🎙 Aivis Cloud API | 🖥 ローカルエンジン | 🫛 VOICEVOX WEB版 |
|---|---|---|---|
| 設置 | 不要（HTTPS） | PCにインストール | 不要（HTTPS） |
| 費用 | 登録時に無料クレジット、以降は従量課金または月額 | 無料・無制限 | 無料（ポイント制の日次上限あり） |
| 速度 | 生成開始 約0.3秒 | PC性能次第 | 混雑時に失敗あり |
| iPhone | ✅ | ❌ | ✅ |
| 位置づけ | 実用 | 実用（PC限定） | お遊び |

**🎙 Aivis Cloud API**：キーは [ダッシュボード](https://hub.aivis-project.com/cloud-api/dashboard)、モデルUUIDは [AivisHub](https://hub.aivis-project.com/) の各モデルページからコピーします。初期値は「Anneli」です。

> **自分の声のモデルを使う**
> Style-Bert-VITS2 で作ったモデルを AIVM Generator で AIVM / AIVMX に変換し、Aivis Cloud のダッシュボードにアップロードすると、そのモデルUUIDを貼るだけで使えます。**モデルは既定で非公開**なので社内利用でも問題ありません。推論の重さは声によって変わらないため、自分の声にしても速度は落ちません（公称：最速0.3秒でストリーミング開始）。
>
> **ただし Aivis は日本語専用です。**カスタムモデルを作っても英語は出せません（AivisSpeech Engine の仕様として明記されています）。自分の声で英語を話したい場合は **ElevenLabs** をお使いください。

**🖥 ローカルエンジン**：PCで動かしている [AivisSpeech](https://aivis-project.com/)（既定 `http://127.0.0.1:10101`）または [VOICEVOX](https://voicevox.hiroshiba.jp/)（既定 `http://127.0.0.1:50021`）に接続します。API互換なのでURLを変えるだけで両対応です。「🔄 話者取得」でエンジンから話者一覧を読み込めます。

> **エンジンはCORSを許可して起動してください**（例：`run.exe --cors_policy_mode all`）。
> ブラウザがローカル宛の通信を遮断する場合があり、そのときは繋がりません。うまくいかないときは Aivis Cloud API をお使いください。

### 🫛 VOICEVOX（お遊び機能）

読み上げに **VOICEVOX WEB版 API** を選ぶと、ずんだもん・四国めたん・春日部つむぎなどの声で読み上げます。有志が運営する非公式APIを利用するもので、キーは [su-shiki.com/api/](https://su-shiki.com/api/) から無料で取得できます。

- **日本語だけ**この声になります（VOICEVOXは日本語専用）。他の言語はブラウザ内蔵音声で読み上げます
- ポイント制の1日上限があり、混雑時は失敗することがあります。失敗した場合はブラウザ内蔵音声に自動で切り替わります
- 個人利用向けのAPIなので、業務での常用には向きません

**ボイスチェンジャーとして使う**

⚙ → 音声 の「**訳文ではなく原文をそのまま読み上げる**」をONにすると、翻訳を待たずに、認識できた自分の発言をそのまま読み上げます。次の組み合わせで、自分の声がずんだもんになります。

| 項目 | 設定 |
|---|---|
| 読み上げ | 🫛 VOICEVOX WEB版 |
| 読み上げ対象 | 自分(A)の発言だけ |
| 原文をそのまま読み上げる | ON |

会話ログの翻訳表示はこれまで通り出るので、通訳として使いながら声だけ変える、という使い方もできます。リアルタイム同時通訳モードは音声がAPI側から返ってくる仕組みなので、この設定の対象外です。

> **クレジット表記について**
> VOICEVOXの音声を含む録音や書き起こしを公開・配布する場合は、VOICEVOXの規約によりクレジット表記が必要です。
> 例：`VOICEVOX:ずんだもん`
> 選択中の話者に応じた表記は、⚙ → 音声 → VOICEVOX の欄に表示されます（A/Bで別の話者を選んでいる場合は両方が並びます）。

### 🔍 APIキーの事前確認

キーの打ち間違いや権限不足は、**本番で最初の1回が失敗して初めて分かる**のが一番困ります。しかも失敗の見え方（無音・翻訳が出ない）が原因を示してくれません。

そこで、キーの入力欄の下に **「🔍 キーを確認」** ボタンを置いています。押すと一番軽い呼び出しを1回だけ投げて、通るかどうか・通らないなら何が原因かを日本語で表示します。

| 場所 | 確認できること |
|---|---|
| 翻訳・API → API Key | キーの有効性と、そのアカウントで使えるモデル数 |
| 音声 → 音声認識用キー | キーの有効性（リアルタイム同時通訳モードは接続可否まで） |
| 音声 → ElevenLabs | キーの有効性と**残り文字数**・プラン名 |
| 音声 → Aivis Cloud API | キー**とモデルUUID**の両方（ごく短いテスト音声を1回生成します） |
| 音声 → VOICEVOX WEB版 | キーの有効性と**残ポイント**（あと何回読めるか） |
| 音声 → ローカルエンジン | エンジンが起動しているか、CORSが開いているか |

失敗の理由は原因ごとに書き分けます。

- **キーが違う / 権限がない**（401・403）… 貼り付け時に空白や改行が混ざっていないか
- **回数制限か残高切れ**（429）… 請求設定・残クレジットの確認
- **相手側の一時的な障害**（5xx）… 時間をおく
- **ブラウザから接続できない**… ネットワーク、またはCORSが許可されていない

キーやモデルUUIDを打ち直すと前回の判定は自動的に消えるので、古い結果を信じてしまうことはありません。

### 📖 用語集・会議の背景

社内用語や製品名を「原語 → 訳語」で登録しておくと、AI翻訳がそれに従います。CSVで読み書きできるので、Excelやスプレッドシートで編集できます。

「会議の背景」に文脈（業種・相手・議題など）を書いておくと訳の精度が上がります。どちらもAI翻訳プロバイダ選択時のみ有効です。

### 📝 ログ・議事録

- 会話ログをテキスト / CSV でダウンロード
- AIに議事録を自動生成させる
- 🩺 **診断ログ**：環境・設定・動作の記録・会話ログをまとめて出力（不具合報告用。APIキーは自動で伏せ字になります）

### 🖥 表示の自由度

- **左右2分割 / 上下2分割 / 自分だけ / 相手だけ** を1ボタンで切り替え
- 相手側パネルの **180°回転**（端末を挟んで対面で置くとき用）
- **A/Bの表示位置の入れ替え**
- 文字サイズの拡大縮小
- **A/Bの会話ログのスクロール連動**（左右で文の長さが違ってもズレないよう、発言単位で位置を合わせます）
- 使用中は画面が自動で暗くならないようにします（Screen Wake Lock）

### 🖥 字幕オーバーレイ表示

操作エリアの **字** ボタンで、背景を透かして字幕だけを浮かせる表示に切り替わります。作業画面に重ねて使うためのモードです。

- 見出し・吹き出しの枠を消し、**直近2〜5件だけ**を大きく表示（件数は変更可）
- 文字に黒い縁取りが付くので、明るい画面に重ねても読めます
- 背景の濃さを 0〜90% で調整できます
- 操作バーは普段は消えていて、画面下にマウスを近づけると出てきます

**ブラウザの窓そのものは透明になりません。**ページの背景を変えるだけなので、実際にデスクトップへ重ねるには次のどれかと組み合わせます。

**① Windowsで重ねる（推奨・クロマキー方式）**

背景を **マゼンタ** にして、同梱の `overlay-helper.ahk`（[AutoHotkey v2](https://www.autohotkey.com/) が必要）を実行し **Ctrl+Alt+T**。

その色だけがWindows側で抜かれるので、**文字は不透明のままくっきり残り、背景だけが完全に透けます。**窓ごと薄くする方式と違って字幕が読みづらくなりません。クリックも下のアプリに通るので、字幕の上からそのまま作業できます。

| キー | 動作 |
|---|---|
| `Ctrl+Alt+T` | 字幕モード＋最前面固定＋クロマキー＋クリック透過を一括で ON / OFF |
| `Ctrl+Alt+↑ / ↓` | 全体の濃さ |
| `Ctrl+Alt+K` | 抜く色を切替（マゼンタ / 緑 / 黒） |
| `Ctrl+Alt+O` | アプリの字幕モードだけを切替（アプリ側の機能） |

**② OBSのブラウザソース**：背景を **透明** にすると完全に透過します。配信・録画に重ねるならこれ。

**③ 窓ごと半透明**：背景を透明にして、[PowerToys の「常に手前に表示」](https://learn.microsoft.com/ja-jp/windows/powertoys/always-on-top)（Win+Ctrl+T）＋ウィンドウ透過ツールで窓全体を薄くします。手軽ですが文字も一緒に薄くなります。

> クリック透過中はウィンドウをクリックできません。設定は先に済ませてから掛けてください。キー操作は常に効くので `Ctrl+Alt+T` でいつでも戻せます。

## 画面の見かた

```
┌─────────────────────────┐
│ B  相手 / Partner · English   │  ← 相手側パネル（相手の言語で表示）
│                              │
│  発言が英語で並ぶ              │
├─────────────────────────┤
│ A  自分 / Me · 日本語          │  ← 自分側パネル（自分の言語で表示）
│                              │
│  同じ発言が日本語で並ぶ         │
├─────────────────────────┤
│ [話者:自動][入力欄][送信][✕]  │  ← テキスト入力バー（⌨で開閉）
├─────────────────────────┤
│ ● 開始  A 日本語  B English   │  ← 操作エリア
│ 配置  A− A＋  🔊 ⌨ 📷 🗑 ⚙  │
└─────────────────────────┘
```

同じ発言が両方のパネルに、それぞれの言語で表示されます。**A = 自分（緑）**、**B = 相手（ピンク）** で色分けされています。

## 操作エリアのボタン

| ボタン | 説明 |
|---|---|
| **● 開始 / ■ 停止** | 音声認識の開始・停止 |
| **A / B の言語** | 話者ごとの言語を選択 |
| **言語切替** | 聞き取り言語の切り替え方（手動 ⇄ AUTO）。無料モードでは非表示 |
| **認識中言語** | いま聞き取っている言語。押すとA↔Bを切り替え |
| **配置** | 表示レイアウトの切り替え（`H：A/B` = 左右、`V：A/B` = 上下、`V：A` / `V：B` = 片側だけ）。枠の色が実際の並び順を表します |
| **A− / A＋** | 文字サイズ |
| **🔊** | 読み上げ ON / OFF（OFFのときは斜線が入ります） |
| **⌨** | テキスト入力欄の開閉 |
| **📷** | カメラ翻訳 |
| **🗑** | 会話ログの消去 |
| **⚙** | 設定 |

## 無料で使う / APIを使う

### 完全無料の組み合わせ

- 翻訳プロバイダ = **無料モード**
- 音声認識 = **ブラウザ内蔵 Web Speech API**
- 読み上げ = **ブラウザ内蔵音声**

APIキー不要・課金なし。ただし Chrome / Edge・マイク入力のみで、用語集とコンテキストは効きません。

### APIを使うと良くなること

- 用語集・会議の背景が翻訳に反映される
- 訳文の精度と自然さが上がる
- 音声認識が Safari / iPhone でも安定して動く
- AUTO（A/B自動交互）が使える
- カメラ翻訳・AI議事録が使える

APIキーは各社のコンソールで取得して、⚙ → 翻訳・API に貼り付けてください。

## プライバシーとAPIキーの扱い

- **サーバーはありません。** すべてブラウザ内で動きます。会話ログが開発者に送られることはありません
- 翻訳・音声認識・読み上げは、**選んだプロバイダのAPI**に直接送信されます。何をどこに送るかは、選んだプロバイダで決まります
- APIキーは端末の `localStorage` に保存されます（「キーを記憶する」がONのとき）。共用PCではOFFにしてください
- カメラ翻訳は**写真を保存しません**。1コマをメモリ上で切り出して送るだけです
- 診断ログはAPIキーを自動で伏せ字にしますが、**会話内容は含まれます**。共有前に中身を確認してください

> ### ⚠️ HTMLの書き出しについて
> 「APIキーも埋め込む」をONにして書き出したHTMLには、**APIキーが平文で含まれます。**
> このファイルを公開リポジトリにコミットしたり、他人に渡したりしないでください。配布用のファイルは必ずOFFのまま書き出してください。

## 困ったときは

**音声認識が始まらない / すぐ止まる**
- マイクの許可を確認してください（アドレスバー左の 🔒 → マイク → 許可）
- `https://` のURLか `localhost` である必要があります。HTMLファイルを直接開いた（`file://`）状態ではマイクを使えません
- iPhone / iPad で無料モードが動かない場合は、音声認識をAPIに切り替えるか、PCのChromeでお試しください

**翻訳が失敗する**
- 無料モードは非公式エンドポイントのため、混雑時に失敗することがあります（自動でMyMemoryに切り替わります）
- APIモードで「モデル名が正しくない」と出る場合は、モデル欄の **🔄 更新** を押して選び直してください

**読み上げが鳴らない**
- 端末がサイレントモードになっていないか確認してください
- iOSは「一度画面をタップしてから」でないと音が出ない仕様です。開始ボタンを押した後にもう一度画面をタップしてみてください

**周りの人の声を拾ってしまう**
- 指向性のある外付けマイク（ピンマイクなど）を使うと大きく改善します。ソフト側の設定では解決できない部分です

**それでも直らないとき**
- ⚙ → 表示・記録 → 🩺 診断ログ の「コピー」または「ファイルDL」で出力したものを、Issue に貼り付けてください。環境・設定・動作の記録がまとまっています（**会話内容が含まれるので、貼る前に中身を確認してください**）
