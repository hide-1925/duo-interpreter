# Duo Interpreter

対面・オンライン会議の会話を、その場で双方向に通訳または文字起こしするWebアプリです。HTML 1ファイルだけで動きます。

画面を上下（または左右）に分割して、**自分side（A）** と **相手side（B）** にそれぞれの言語で会話ログを表示します。スマホをテーブルに置いて相手と挟んで使う、PCの画面を一緒に覗き込む、オンライン会議の画面共有時に翻訳をオーバーレイ表示、読上げ音声で会話といった使い方を想定しています。

**👉** [**https://hide-1925.github.io/duo-interpreter/**](https://hide-1925.github.io/duo-interpreter/)

インストール不要・アカウント登録不要。**APIキーなしの完全無料でも動きます。**

## v1.37.2 の変更

- 画面取込設定へ`取込音声`を追加しました。`対象の音声のみ（推奨）`、`システム全体の音声`、`音声を取り込まない`から選択できます。
- 既定の`対象の音声のみ`では、Chromeタブの音声または対応ブラウザのウィンドウ音声を要求します。`systemAudio: exclude`と`windowAudio: window`を使用します。

- オーバーレイを開かず、入力元の`画面`から直接音声を取得するSTT経路にも同じ音声ポリシーを適用しました。
- 設定変更は次回の`画面取込`から反映します。診断ログへ要求モード、`systemAudio`、`windowAudio`および実際の共有面を記録します。

## v1.35.0 の変更

- 開発仕様書のPhase 2へ進み、タブ／システム音声のSTT経路を「直接Web Speech（無料）／VB-CABLE入力（互換）／外部API（高精度）」から明示選択できるようにしました。
- Chrome／Edge 135以降では、画面取込で取得した共有音声`MediaStreamTrack`を`SpeechRecognition.start(audioTrack)`へ直接渡します。認識が自動終了して再起動する際も同じTrackを再利用し、非対応時は既定マイクへ黙って切り替えません。
- オーバーレイで既に共有音声を取得している場合は同じTrackをSTTへ再利用し、画面共有ダイアログを重ねて開きません。共有音声が無い場合はVB-CABLE／外部API経路を案内します。
- 通常マイクとVB-CABLE入力のデバイス選択を分離しました。A=通常マイク、B=仮想ケーブルの会議音声という構成を維持できます。
- 外部TTSの出力先を「自分向け（B→A：ヘッドホン／スピーカー）」と「相手向け（A→B：CABLE Input等）」へ分離しました。OpenAI、Aivis、ElevenLabs、xAI、VOICEVOX、ローカルエンジンの席情報を再生キューまで保持して、発話方向ごとのsinkへ送ります。
- ブラウザ内蔵`speechSynthesis`は出力先を分離できないため、設定欄に制約を表示します。ブラウザが対応する場合は出力先選択ダイアログも利用できます。
- STT入力とTTS出力が同じVB-CABLE系統になる構成を検出して警告し、既定ONの自己認識防止では認識中の該当TTSを停止します。生声と翻訳TTSを会議へ同時送出する場合はVoicemeeter等で別経路を合成してください。
- 共有音声Track／共有元の終了時は、そのTrackを使用中のSTTを停止し、残存TTSも停止します。
- 会話カードの読み上げ停止判定をDOMボタンの同一性から会話カードIDへ変更しました。再描画後でも同じカードの再生ボタンをもう一度押すと停止します。
- 後方互換の機能追加としてDuo Interpreter v1.35.0 Phase 2へ更新しました。ビルドIDは`20260902-v1350-audio2.0`です。

## 3分ではじめる

1. 上のURLをブラウザで開く
2. **⚙** → 「翻訳・API」タブ 
   - 翻訳プロバイダ = **🆓 無料モード**
3. 「音声」タブ 
   - 音声認識 = **🆓 ブラウザ内蔵 Web Speech API**
   - 読み上げ = **🆓 ブラウザ内蔵音声**
4. 閉じて、操作エリアで **A / B の言語**を選ぶ（既定は A=日本語、B=English）
5. **● 開始** を押してマイクを許可 → 話す

これでAPIキーなし・課金なしで通訳が動きます。

## できること

### 🎤 音声を聞き取って、その場で翻訳

話した内容を認識して、もう片方の言語に翻訳し、両方のパネルに表示します。翻訳結果は音声で読み上げることもできます。

聞き取る言語の切り替えは **手動**（ボタンかパネルのタップ）と **AUTO**（A/B交互に自動で切り替え）が選べます。無料モード（ブラウザ内蔵の音声認識）では、認識エンジンが1言語ずつしか扱えない都合でAUTOは使えません。手動固定になります。

### 📝 翻訳せず文字起こしだけ行う

**⚙ → 翻訳 → AIプロバイダ → なし（文字起こしのみ）**を選ぶと、STTの確定結果を翻訳せず会話ログへ蓄積します。

- 翻訳APIと訳文TTSは呼び出しません
- 原文を翻訳後テキストと同じ主表示・同じ文字サイズで表示します
- 音声入力とキーボード入力の両方を利用できます
- TXT／CSV／診断ログへ保存できます
- 原文読み上げをONにした場合だけ、認識直後の原文TTSは引き続き動作します

### ⌨ キーボード入力にも対応（言語は自動判定）

操作エリアの **⌨** ボタンで入力欄が開きます。打った文章がA・Bどちらの言語かを自動で判定して、もう片方の言語に翻訳します。**言語を選ぶ操作は不要です。**

- 判定は端末内で完結（文字種＋その言語らしい単語・アクセント記号で採点）。通信は発生しません
- ラテン文字同士（英↔独、西↔葡など）で判定が割れたときだけ、Google翻訳の言語判定（無料・キー不要）に問い合わせます
- 判定を使いたくないときは、入力欄左の「話者」ボタンで **A固定 / B固定** に切り替えられます
- Enterで送信、Shift+Enterで改行。日本語入力の変換確定Enterでは送信されません

騒がしい場所、固有名詞や数字を正確に伝えたいとき、音声認識がうまくいかないときの保険として使えます。

### 📷 カメラで文字を翻訳

**📷** ボタンでカメラが起動します。画面をタップした瞬間の1コマだけを読み取り、写っている文字をA話者の言語に翻訳します。看板・メニュー・書類などに。

- **写真は端末に一切保存されません**（メモリ上の1コマをそのまま画像認識に送るだけ）
- 結果は「＋ 会話ログに追加」で会話ログに残せます
- 画像を読めるAIモデルが必要なので、無料モードでは使えません

### 🔊 読み上げ

翻訳結果を音声で読み上げます。「相手(B)の発言だけ」「両方」などを選べます。

各発言の吹き出しにある **🔊** ボタンを押せば、読み上げ設定がOFFでもその1文だけを読み上げられます（そのパネルに表示されている文章をそのまま読みます）。

読み上げている間はそのボタンがゆっくり点滅します。\*\*もう一度押すと途中で止められます。\*\*別の発言の🔊を押した場合は、前の読み上げを止めてそちらに切り替わります。

#### 話者A / B で声を分ける

読み上げ対象を「両方」にすると、どちらの発言を聞いているのか分からなくなりがちです。そこで **自分(A) と 相手(B) で別の声**を設定できます。⚙ → 音声 に、選んだエンジンごとの2列（左＝自分(A) / 右＝相手(B)）が出ます。

| エンジン A/B別の声      |                     |
| ---------------- | ------------------- |
| OpenAI 音声        | 13種類の声から個別に選択       |
| xAI Grok Voice   | 28種類の声から個別に選択       |
| ElevenLabs       | 声を個別に選択（自分の声も含む）    |
| Aivis Cloud API  | キャラ（モデル）とスタイルを個別に選択 |
| 🖥 ローカルエンジン      | 話者を個別に選択            |
| 🫛 VOICEVOX WEB版 | 話者を個別に選択            |
| 🆓 ブラウザ内蔵音声      | 設定なし（言語ごとに自動で選ばれます） |

- 読み上げ対象が「相手(B)だけ」「自分(A)だけ」のときは、使わない側の列は自動で隠れます
- Aivis Cloud・ElevenLabs・xAI・ローカルエンジンは、**自分(A)側が本命**です。相手(B)側を「自分(A)と同じ」のままにしておけば、A席に選んだ声が両方に使われます
- 日本語専用エンジン（Aivis / ローカル / VOICEVOX）は、日本語で読む発言だけがその声になります。もう一方の言語はブラウザ内蔵音声です

#### 元音声の話し方をできるだけ保持する［実験］— v1.32.8 Phase 1

⚙ → 音声 の **「元音声の話し方をできるだけ保持する［実験］」**をONにすると、元音声から以下を発話ごとに計測します。

- Pitch：基本周波数（声の高さ）の平均・範囲・8点の輪郭
- Energy：RMSから計算した音量の平均・ピーク・範囲
- Pause：直前発話からの間に加え、発話内部の無音位置・長さ・無音率
- Speech Rate：発話全体の速度と、有声部分だけのArticulation Rate（調音速度）
- Confidence：有声/Pitchフレーム数に加え、実発声の被覆率、音声の断片化、最大内部無音から算出した解析信頼度
- Rate Confidence：発声時間・文字/単語数・区間品質から、話速を安全に反映できるかを判定した専用信頼度

解析は端末内で行い、音声や解析値を新しい外部サービスへ送りません。発話ごとの要約は会話データと診断ログへ保存されます。Pitchが取れない場合も翻訳・読み上げは通常どおり続行します。

音声判定のしきい値は、STT用の「マイク感度」と分離しています。マイク入力の静かなフレームからノイズ床を推定し、0.008～0.035 RMSの範囲で自動調整します。そのため、STTのVAD設定を上げ下げしてもProsody解析値は直接変わりません。

Web Speech APIは認識文字へ音声の時刻を返しません。このため、前回の認識確定から蓄積した波形を1.2秒以上の無音で音響クラスタへ分割し、確定直前の有効なクラスタだけを認識文へ対応付けます。前回のTTS回り込みや待機中の環境音が別クラスタなら除外します。末尾の1～2フレームだけのノイズも発話として選びません。API STTは録音VADで既に区切られているため、この選別を行いません。

話速には、認識確定までの待機時間を含むSpeech Rateではなく、実際に声が出ていた時間だけで割るArticulation Rate（調音速度）を使用します。ただし短い発話では文字数÷時間の誤差が大きいため、次を満たす発話だけを速度基準に使います。

- Active Speech 900ms以上
- 日本語などの文字単位言語は6文字以上、単語単位言語は4単語以上
- Coverage 55%以上
- Confidence 0.65以上、Timing Confidence 0.60以上

有効発話が3件集まるまでは速度補正を1.0にします。ウォームアップ中は、言語別の標準速度に対する許容範囲を30～220%まで広げ、高品質な遅い発話も基準候補として受け入れます。3件目の後、実測3件と言語別シード2票の計5値から中央値を取り、本人の初期基準にします。これにより会話冒頭の意図的な早口・遅口1件に引きずられにくくしながら、実測値も基準へ反映します。

基準確定後は従来どおり、現在基準の60～160%を外れる極端な発話を通常基準の学習から除外します。その後は有効発話5件ごとに直近最大12件の中央値へ20%だけ再基準化します。直近3件がすべて基準より20%以上速い、または遅い場合は、会話全体のテンポが変わったとみなして35%追従します。極端な演技は速度表現には使いますが、通常基準の学習からは除外します。

速度は細かな連続値ではなく、Aivisとブラウザ標準TTSの両方で次の5段階へ分類します。4%のヒステリシスを設け、境界付近で速度が往復しないようにします。

| 現在速度 ÷ 基準速度 | 判定 | 補正倍率 |
|---:|---|---:|
| 0.78未満 | かなり遅い | 0.82 |
| 0.78～0.92 | 遅い | 0.90 |
| 0.92～1.10 | 通常 | 1.00 |
| 1.10～1.28 | 速い | 1.15 |
| 1.28以上 | かなり速い | 1.30 |

短い命令文・相づちは速度だけを1.0へ戻します。発話全体のConfidenceがmedium以上なら、Pitch・Energy・緩急はそれぞれの信頼度に応じて反映を続けます。各音響クラスタの先頭10有声フレームはPitchを毎フレーム解析し、短文でも取得数を増やします。

Pitch・Energy・表現幅もA/B各話者と言語ごとに相対化します。最初の有効なPitch幅・Energy幅をその話者の基準とするため、固定値との個人差で最初から緩急が上限へ張り付きません。

ブラウザ標準TTS、Aivis Cloud API、VOICEVOX WEB版では、計測値を次のように反映します。

| TTS | 反映するもの | 反映しないもの |
|---|---|---|
| ブラウザ標準 | 発話全体の速度・音量、話者基準のPitch平均差と語尾傾向 | 単語単位の強調、途中の細かなPitch contour |
| Aivis | 既存の手動設定を基準に、`speaking_rate`・`tempo_dynamics`・`volume`を補正 | 感情パラメータ、絶対Pitch、単語単位の強調 |
| VOICEVOX WEB版 | 既存の手動話速を基準に、端末側の`playbackRate`を補正 | API合成時の声高・抑揚・音量、単語単位の強調 |

速度は0.82 / 0.90 / 1.00 / 1.15 / 1.30の5段階です。v1.32.6では聞き分けやすさを優先して各段階の差を広げました。Pitchは0.90～1.10倍、音量は0.92～1.08倍、Aivisの緩急は0.86～1.16倍の範囲です。解析信頼度がlowの発話は、速度・Pitch・音量・緩急をすべて補正倍率1.0へ戻します。AivisとVOICEVOXの手動調整値は上書きしません。VOICEVOX v3では話速だけが再生時に反映され、Pitch・抑揚値は診断用です。

Prosody解析はAivis API呼び出し前に同期実行しますが、900フレームの合成試験で平均約0.8msでした。Aivisストリーミングの先読みは150msです。v1.32.6では受信完了ではなく実再生終了まで再生ロックを保持し、次の読み上げが重ならないようにしました。待機は`queue-wait`、重なりを防いだ場面は`overlap-prevented`、実再生終了は`stream-play-end`として診断ログへ残ります。

ブラウザ標準TTSの実際の効き方はOSと音声エンジンに依存します。`rate / pitch / volume`を受け取っても、一部の声はPitch差をほとんど再現しません。診断ログには渡した実効値を残します。

発話内部Pauseは選択した音響クラスタ内だけで位置と長さを保存し、Aivisの緩急判定に利用します。ただし、翻訳後テキストのどの語に対応するかはまだ分からないため、同じ位置へ無音を直接挿入してはいません。発話前Pauseも、会話遅延を増やすためTTSへ追加しません。

「読み上げ音声の回り込みを除外する」は既定ONです。Safariでは読み上げを拾った認識結果が数秒遅れて返ることがあるため、従来の30秒照合を維持しています。同じ文章を繰り返す比較試験では、この設定をOFFにしてください。

感情推定、強調語の抽出、単語単位の抑揚反映は未実装です。機能をOFFにすれば従来経路のまま動作します。

### 読み上げをZoom/Teamsのマイクとして流す

自分（話者A）が話した内容を合成音声で読み上げ、それを **Teams や Zoom のマイク入力として相手に届ける**ための設定です。仕組みが分かればエコー対策も自然に決まるので、まず音の通り道から。

#### 音の通り道

```
        自分の声（マイク）
              │
              ▼
       Duo Interpreter          認識 → 翻訳 → 音声合成
              │
              │  ① 読み上げの出力先
              ▼
        CABLE Input             ← 再生デバイス
              │
              │  Windows が中で直結
              ▼
        CABLE Output            ← 録音デバイス
              ├──── ③ このデバイスを聴く ───▶ ヘッドホン（自分の耳）
              │
              │  ② Teams のマイク
              ▼
         Teams / Zoom
              │
              ▼
           相手に届く

```

合成音声は**物理的なスピーカーを通らずに** `CABLE Input` へ入り、Windows の中で `CABLE Output` に出てきます。Teams はそれをマイクとして読み取ります。設定するのは **① ② ③ の3か所だけ**です。

#### 設定する3か所

`CABLE Input` と `CABLE Output` の取り違えが、いちばん多いつまずきです。**流し込む先が Input、出てくる先が Output** と覚えてください。

| どこ 何を  |                 |                                                                                                              |
| ------ | --------------- | ------------------------------------------------------------------------------------------------------------ |
| ①      | Windows         | 設定 → サウンド → 録音 → `CABLE Output` のプロパティ → **「聴く」タブ** → 「このデバイスを聴く」にチェック → 再生先に**ヘッドホン**を指定                    |
| ②      | Duo Interpreter | 読み上げの出力先 = `CABLE Input` ／ 読み上げ対象 = **自分(A)の発言だけ** ／ 原文読み上げ = **ON** ／ 読み上げ = Aivis・ElevenLabs・OpenAI音声のいずれか |
| ③      | Teams / Zoom    | マイク = `CABLE Output` ／ スピーカー = **ヘッドホン** ／ **ノイズ抑制 = オフ**                                                    |

仮想オーディオケーブルは OS ごとに次のものを使います。

| OS ソフト 備考  |                                                  |                                  |
| ---------- | ------------------------------------------------ | -------------------------------- |
| Windows    | [VB-CABLE](https://vb-audio.com/Cable/)          | 単純な1本のケーブル。**インストールに管理者権限が要ります** |
| Windows    | [VoiceMeeter](https://vb-audio.com/Voicemeeter/) | 自分の生声と読み上げを混ぜられる                 |
| macOS      | BlackHole                                        | 単純な1本のケーブル                       |
| macOS      | Loopback（有料）                                     | 混合・分岐ができる                        |

> **ノイズ抑制は必ず切ってください。** Teams も Zoom も「人の声らしくない音」を削る処理を入れており、合成音声が**途切れたり、こもったり**します。Teams は 設定 → デバイス → ノイズ抑制 → オフ、Zoom は 設定 → オーディオ → 背景ノイズの抑制 → 「低」か「無効」です。

#### エコーを起こさない3つの約束

どれか1つでも破ると、音がぐるぐる回り始めます。

1. **ヘッドホンを使う。スピーカーは使わない。**
   合成音がスピーカーから出ると、それを自分のマイクが拾い、また読み上げられ…と無限に回ります。**ヘッドホンにするだけで、この経路は物理的に存在しなくなります。**
2. **読み上げ対象は「自分(A)の発言だけ」にする。**
   「両方」にすると、相手が話した内容の訳文まで `CABLE Input` に流れ、**相手に相手自身の声が返ります**。相手側で盛大なエコーになります。
3. **自分の読み上げが終わるまで、次を話さない。**
   読み上げ中に話し始めると、相手には2つの発言が重なって届きます。**相手からは、あなたが2〜4秒遅れて話しているように見えます。**

> **アプリ側の保険**
> 万が一マイクが合成音を拾ってしまっても、アプリは直前30秒に読み上げた文と照らし合わせて、似ていれば捨てます（2文字ずつの重なり具合で判定し、6割以上一致したらエコーとみなします）。誤って本物の発言を消さないよう、8文字未満の短い文は判定の対象外です。捨てたことは診断ログに `echo-drop` として残ります。
> 同じ文章を繰り返す音声比較では、⚙ → 音声の「読み上げ音声の回り込みを除外する」をOFFにできます。通常利用ではONを推奨します。
> ただしこれは**最後の防波堤**であって、ヘッドホンの代わりにはなりません。

#### うまくいかないとき

| 症状 いちばん多い原因 直し方  |                                  |                                                                      |
| ---------------- | -------------------------------- | -------------------------------------------------------------------- |
| 相手に何も聞こえない       | Teams のマイクが `CABLE Input` になっている | マイクは **Output** のほうです                                                |
| 自分に何も聞こえない       | 「このデバイスを聴く」が未設定                  | ①の手順で設定します。**音は正常に流れています**                                           |
| 既定のスピーカーから鳴る     | 読み上げがブラウザ内蔵音声になっている              | Aivis などのAPI系に切り替えます                                                 |
| 相手側でエコーが起きる      | 読み上げ対象が「両方」                      | 「自分(A)の発言だけ」にします                                                     |
| 合成音がブツ切れになる      | Teams のノイズ抑制                     | オフにします。直らなければ Aivis のストリーミング再生を切って試します                               |
| プツプツとノイズが入る      | サンプルレートの不一致                      | `CABLE Input` と `CABLE Output` の「詳細」タブで既定フォーマットを揃えます（両方 48000 Hz など） |

#### そのほかの制約

- **ブラウザ内蔵音声には効きません。** `speechSynthesis` は仕様上、既定のスピーカーからしか鳴らせないためです。OpenAI音声とVOICEVOXでご利用ください
- **Safari / Firefox など、Web Audio 側が出力先の指定に対応していないブラウザ**では、Aivis のストリーミング再生を自動的に切って従来方式に回します。ストリーミングのままだと指定した機器ではなく既定のスピーカーから鳴ってしまうためです。切り替えたことは診断ログに `aivis-stream-skip` として残ります
- 対応ブラウザは Chrome / Edge のデスクトップ版が中心です。Safari・iPhone・iPadでは選択肢が出ません
- ケーブルをマイクにすると**自分の生声は相手に届きません**。両方流すには VoiceMeeter / Loopback での合成が必要です
- 会議音声を「タブ音声」で認識させている場合、読み上げが会議に戻ってループしないようご注意ください
- デバイス名が出ないときは、一度「● 開始」でマイクを許可してから 🔄 更新 を押してください（ブラウザの仕様でマイク許可後にデバイス名が読めるようになります）

### 🗣 自分の声で読み上げる

読み上げを自分の声にする道は2つありますが、**かかる手間がまるで違います**。大きな分かれ目は「**英語を喋らせたいかどうか**」です。

| 🗣 ElevenLabs 🎙 Aivis  |          |                        |
| ----------------------- | -------- | ---------------------- |
| 所要                      | **5分ほど** | 半日〜数日                  |
| 必要な音声                   | 1〜2分     | 10〜45分                 |
| 必要な機材                   | マイクだけ    | NVIDIA GPU（無ければ Colab） |
| 言語                      | 日本語・英語ほか | **日本語のみ**              |

#### ElevenLabs でつくる（5分）

1. **1〜2分ぶんの音声を録る。** 原稿は何でも構いません。メールの文面を音読するくらいで十分です
2. **プランに入る。** 声のクローンは**無料プランでは使えません**。いちばん安い Starter（月 $6・3万クレジット）から
3. [Voice Lab](https://elevenlabs.io/app/voice-lab) で **＋ → Instant Voice Clone** を選び、録音をアップロード
4. 名前を付けて、権利の確認にチェックして保存。**ここで完成です。学習の待ち時間はありません**
5. [API Keys](https://elevenlabs.io/app/settings/api-keys) でキーを取得し、⚙ → 音声 → ElevenLabs に貼って「🔄 声を取得」

自分でクローンした声は一覧の**先頭**に出てきます（`cloned` → `professional` → `premade` の順に並べ替えています）。

| プラン 月額 クレジット かんたん複製 本格複製  |     |         |   |   |
| ------------------------- | --- | ------- | - | - |
| Free                      | $0  | 10,000  | × | × |
| Starter                   | $6  | 30,000  | ○ | × |
| Creator                   | $22 | 121,000 | ○ | ○ |

「本格複製」は Professional Voice Cloning のことで、30分以上の音声からより忠実な声を作る機能です。**通訳用途ならかんたん複製（Instant）で十分**なので、Starter から始めて構いません。

#### Aivis でつくる（半日〜）

Style-Bert-VITS2 で学習させ、AIVM に変換して、Aivis Cloud に上げる、という3段構えです。

1. **音声を集める。** 目安は10〜45分。公式FAQも「どれくらい必要かは分からないので試してほしい」と正直に書いています。1本の長い録音で構いません
2. [**Style-Bert-VITS2**](https://github.com/litagin02/Style-Bert-VITS2) **を用意する。** NVIDIA の GPU があれば手元のPCで、無ければ[公式の Colab ノートブック](https://colab.research.google.com/github/litagin02/Style-Bert-VITS2/blob/master/colab.ipynb)で動かせます
3. **データセット作成タブに音声を放り込む。** 2〜14秒ずつに自動で切り分け、書き起こしまで自動です
4. **学習タブで回す。** 2,000〜3,000ステップで声が似始め、5,000〜15,000ステップで実用域が目安。終わると `*.safetensors`・`config.json`・`style_vectors.npy` の3つができます
5. [**AIVM Generator**](https://aivm-generator.aivis-project.com/) **で変換する。** その3ファイルを上げると、数分で AIVM と AIVMX の2形式になります
6. [**Aivis Cloud にアップロード**](https://hub.aivis-project.com/cloud-api/models)**する。** 数分で使えるようになり、**既定では非公開**です。あとはモデル UUID を貼るだけ

> Aivis Project は「まるなげボイス」という代行サービスもやっていて、手持ちの録音からモデルを作ってもらえます（**15万円**）。自分で学習する時間を買う、という考え方です。

#### 録音のコツ（どちらの道でも共通）

仕上がりの大半は元の録音で決まります。

- **静けさ** — 反響と雑音がいちばんの敵です。カーテンのある部屋で、エアコンとPCのファンを止めて。会議室のような硬い部屋は響くので不向きです
- **距離** — マイクから**こぶし1つ分**ほど離れ、その距離を保ちます。近づいたり離れたりすると音量が揺れ、AIがその揺れごと覚えます
- **話し方** — **普段の読み方で。** アナウンサーのように気合を入れると、そういう声のモデルができます。通訳用途なら淡々としているほうが後で聞きやすいです
- **音量** — ElevenLabs は `-23 〜 -18 dB RMS`、ピーク `-3 dB` を推奨。音が割れておらず小さすぎなければ大丈夫です
- **形式** — MP3 なら **128 kbps 以上**。スマホのボイスメモでも、静かな場所なら十分実用になります

> **AIは聞こえたものを全部真似ます。** 話す速さも、抑揚も、訛りも、息継ぎまで。早口で感情豊かに喋れば、そういう声ができます。

#### 使うモデルを選ぶ（ElevenLabs）

| --------------------- | ------------------------- |
| **Flash v2.5**        | 公称75ms級・32言語。**同時通訳ならこれ** |
| Multilingual v2       | 高品質・29言語。そのぶん待ちが伸びます      |
| Turbo v2.5 / Flash v2 | 旧世代・英語のみ                  |

**日本語専用エンジンとの一番の違いは、言語を選ばないこと**です。A席の英訳もB席の和訳も同じ自分の声で読めるので、両方を1つの声に揃えられます。

> **⚠ 声の複製について**
> 本人の同意なく他人の声を複製することは、ElevenLabs の規約でも法令でも認められません。自分の声、または明確な許諾を得た声だけをお使いください。

### xAI Grok Voice で読み上げる

日本語・英語を含む **20言語** に対応した読み上げエンジンです。ElevenLabs と同じく多言語なので、日本語専用エンジンのような「片方だけブラウザ内蔵音声になる」制約がありません。

- キーは [xAI コンソール](https://console.x.ai/) で取得します
- **翻訳プロバイダで xAI を使っているなら、音声側のキー欄は空欄のままで動きます**（同じキーを共有します）
- 声は **28種類**（`eve` / `luna` / `orion` など）。どの声でも対応言語すべてを読めるので、A席とB席で別の声にすると、どちらの発言か耳で分かります
- 読み上げる言語は席ごとの言語設定から自動で渡します。対応一覧にない言語（タイ語・オランダ語・ポーランド語など）のときは言語指定を送らず、xAI 側の自動判定にまかせます。設定の要約欄にその旨が出ます

**🎙 Aivis Cloud API**：キーは [ダッシュボード](https://hub.aivis-project.com/cloud-api/dashboard) で取得します。

**キャラは名前のプルダウンから選べます。** 自分(A)の欄で選び、相手(B)を別のキャラにしたいときだけ下の欄を変えます（既定は「自分(A)と同じ」）。常時表示は「まお」から「桜音」までで、「にせ」以降の候補は「その他のキャラ」を開くと選べます。保存済みのキャラが折りたたみ側にある場合は、自動で開いて現在値を見せます。右の「**↗**」でそのモデルの AivisHub ページが開きます。

一覧に入っているキャラ：

> まお / こはく / れな / 阿井田 茂 / 桜音 / にせ / まい / fumifumi / morioki / 凛音エル / 花音 / ろてじん（長老ボイス） / るな / 中2 / ほのか / 観測症 / 猩々博士（雑談ボイス） / らせつん / みちのくあいり / 澤原 玄二郎 / Shinjou Tomoharu / M2 / 天深シノ / zonoko / かりん

**一覧に無いモデル**（自分で作ったモデルを含む）は「**── その他（モデル UUID を貼り付け）──**」を選ぶと入力欄が出ます。貼り付けるのは **モデル UUID** です。[AivisHub](https://hub.aivis-project.com/) の各モデルページ →「**詳細情報**」→「**モデル UUID**」の値で、モデルページのURL末尾と同じ値です。同じ画面にある「**話者 UUID**」ではないので注意してください。

```
https://hub.aivis-project.com/aivm-models/47e53151-a378-46f3-abee-ce13aa07feb1
                                          └──────── これがモデル UUID ────────┘

```

隣の**キャラ名**の欄は、その UUID を覚えておくための目印です（読み上げの動作には影響しません）。AivisHub から自動で取りにいきますが、**AivisHub はブラウザからの読み取りを自分のサイト以外に許していない**ため、多くの場合は自動で入りません。その場合はご自分で書いてください。UUID ごとに覚えるので、貼り替えて戻せば名前も戻ります。

> **自分の声のモデルを使う**
> 自分で学習させたモデルも、モデル UUID を貼るだけで同じように使えます。作り方は [🗣 自分の声で読み上げる](https://claude.ai/cowork/cse_01CzqbhLSFt5YmTfRrr7Y1Lu#-%E8%87%AA%E5%88%86%E3%81%AE%E5%A3%B0%E3%81%A7%E8%AA%AD%E3%81%BF%E4%B8%8A%E3%81%92%E3%82%8B) を参照してください。**モデルは既定で非公開**なので社内利用でも問題ありません。推論の重さは声によって変わらないため、自分の声にしても速度は落ちません。

> **スタイルの使い分け**
> モデルによっては「ノーマル／Calm／Shout」等の演じ分け（スタイル）を持っています。モデルUUIDを入れて「🔄 スタイル取得」を押すと一覧に出ます。
>
> 通訳での一番実用的な使い方は、**A席とB席で違うスタイルにすること**です。1つのモデルのまま、どちらの発言かを声の調子で聞き分けられます。落ち着いた系（ノーマル／Calm）が聞きやすく、Shout や Surprise は業務用途には向きません。
>
> **複数の話者を持つモデル**では、話者名を添えて `花子 / Calm (Style ID: 1)` のように並びます。Style ID は話者ごとの通し番号なので、別の人でも同じ番号が出てきます。選ぶと話者も自動で一緒に指定されます。
>
> **スタイル名が取れない場合について**
> AivisHub のモデル情報APIはブラウザからの直接読み取りを許可していないため、環境によってはスタイル**名**を取れません。**設定の誤りではなく、こちらから直せるものでもありません。**
>
> その場合は「🔄 スタイル取得」が続けて**使える番号を自動で割り出します**（読み上げAPI経由で Style ID を順に試します）。`使えるスタイルは 7件（Style ID 0, 1, 2, 3, 4, 5, 6）` のように出て、そのまま選べるようになります。並び順は AivisHub のスタイル欄と同じなので、0＝いちばん上、と読み替えてください。
>
> 1回あたり1文字ぶんしか消費しないので費用はごくわずかです。どの声か迷ったら「🔍 確認して試聴」で実際に鳴らして確かめられます。
>
> 実在しないスタイルを選べてしまうと事故のもとなので、**こちらで候補をでっち上げることはしません**。

> **話し方の調整**（折りたたみの中）
> Aivis 側が持っているパラメータをまとめて触れます。**既定のままなら何も送らない**ので、開いて眺めるだけなら音は変わりません。動かした項目だけ色が付き、下に「話速 1.2 / 感情 1.4」のように要約が出ます。
>
> | 項目 範囲 使いどころ  |          |                                            |
> | ------------ | -------- | ------------------------------------------ |
> | 話速           | 0.5〜2.0  | 読み上げが会話に遅れがちなときは 1.1〜1.2倍で詰められます           |
> | 感情表現         | 0.0〜2.0  | 選んだスタイルの効き具合。0に近いと平坦、2に近いと大げさ。通訳では1.0前後が無難 |
> | テンポの緩急       | 0.0〜2.0  | 話す速さの揺れ。上げると抑揚がつき、下げると一定のペース               |
> | 音量           | 0.0〜2.0  | 仮想オーディオケーブル経由で相手に小さく聞こえるときに上げます            |
> | 改行時の無音       | 0.0〜2.0秒 | 文の区切りで空ける間。通訳は1文ずつ読むので影響は小さめ               |
> | 音量のノーマライズ    | ON/OFF   | 既定ON。声の大小をそろえます                            |
> | ユーザー辞書UUID   | —        | 社名や製品名の読み方を直したいとき。辞書は Aivis 側で先に作っておきます    |
>
> 変更内容は診断ログの `tweaks` にも残るので、「いつもと音が違う」ときに何を触ったか後から追えます。
> なお `pitch`（声の高さ）は用意していません。Aivis の資料に「品質と生成速度が落ちる」と明記されているためです。

**🖥 ローカルエンジン**：PCで動かしている [AivisSpeech](https://aivis-project.com/)（既定 `http://127.0.0.1:10101`）または [VOICEVOX](https://voicevox.hiroshiba.jp/)（既定 `http://127.0.0.1:50021`）に接続します。API互換なのでURLを変えるだけで両対応です。「🔄 話者取得」でエンジンから話者一覧を読み込めます。

> **エンジンはCORSを許可して起動してください**（例：`run.exe --cors_policy_mode all`）。
> ブラウザがローカル宛の通信を遮断する場合があり、そのときは繋がりません。うまくいかないときは Aivis Cloud API をお使いください。

### 🫛 VOICEVOX（お遊び機能）

読み上げに **VOICEVOX WEB版 API** を選ぶと、ずんだもん・四国めたん・春日部つむぎなどの声で読み上げます。有志が運営する非公式APIを利用するもので、キーは [su-shiki.com/api/](https://su-shiki.com/api/) から無料で取得できます。

- **日本語だけ**この声になります（VOICEVOXは日本語専用）。他の言語はブラウザ内蔵音声で読み上げます
- 折りたたみの「話し方の調整」で、話速（0.50～2.00倍）を変更できます。現行v3では話速を端末側で反映し、声の高さ・抑揚は解析・診断用として保持します
- 話し方保持をONにすると、手動の話速へ5段階速度を乗算します。設定画面の手動値は書き換えません
- ポイント制の1日上限があり、混雑時は失敗することがあります。失敗した場合はブラウザ内蔵音声に自動で切り替わります
- 個人利用向けのAPIなので、業務での常用には向きません

**ボイスチェンジャーとして使う**

⚙ → 音声 の「**訳文ではなく原文をそのまま読み上げる**」をONにすると、翻訳を待たずに、認識できた自分の発言をそのまま読み上げます。次の組み合わせで、自分の声がずんだもんになります。

| 項目 設定        |                  |
| ------------ | ---------------- |
| 読み上げ         | 🫛 VOICEVOX WEB版 |
| 読み上げ対象       | 自分(A)の発言だけ       |
| 原文をそのまま読み上げる | ON               |

会話ログの翻訳表示はこれまで通り出るので、通訳として使いながら声だけ変える、という使い方もできます。リアルタイム同時通訳モードは音声がAPI側から返ってくる仕組みなので、この設定の対象外です。

> **クレジット表記について**
> VOICEVOXの音声を含む録音や書き起こしを公開・配布する場合は、VOICEVOXの規約によりクレジット表記が必要です。
> 例：`VOICEVOX:ずんだもん`
> 選択中の話者に応じた表記は、⚙ → 音声 → VOICEVOX の欄に表示されます（A/Bで別の話者を選んでいる場合は両方が並びます）。

### 🔍 APIキーの事前確認

キーの打ち間違いや権限不足は、**本番で最初の1回が失敗して初めて分かる**のが一番困ります。しかも失敗の見え方（無音・翻訳が出ない）が原因を示してくれません。

そこで、キーの入力欄の下に **「🔍 キーを確認」** ボタンを置いています。押すと一番軽い呼び出しを1回だけ投げて、通るかどうか・通らないなら何が原因かを日本語で表示します。

| 場所 確認できること           |                                      |
| -------------------- | ------------------------------------ |
| 翻訳・API → API Key     | キーの有効性と、そのアカウントで使えるモデル数              |
| 音声 → 音声認識用キー         | キーの有効性（リアルタイム同時通訳モードは接続可否まで）         |
| 音声 → ElevenLabs      | キーの有効性と**残り文字数**・プラン名                |
| 音声 → xAI Grok Voice  | キーの有効性と、そのアカウントで使えるモデル数              |
| 音声 → Aivis Cloud API | キー**とモデルUUID**の両方（ごく短いテスト音声を1回生成します） |
| 音声 → VOICEVOX WEB版   | キーの有効性と**残ポイント**（あと何回読めるか）           |
| 音声 → ローカルエンジン        | エンジンが起動しているか、CORSが開いているか             |

失敗の理由は原因ごとに書き分けます。

- **キーが違う / 権限がない**（401・403）… 貼り付け時に空白や改行が混ざっていないか
- **回数制限か残高切れ**（429）… 請求設定・残クレジットの確認
- **相手側の一時的な障害**（5xx）… 時間をおく
- **ブラウザから接続できない**… ネットワーク、またはCORSが許可されていない

キーやモデルUUIDを打ち直すと前回の判定は自動的に消えるので、古い結果を信じてしまうことはありません。

- 使用中は画面が自動で暗くならないようにします（Screen Wake Lock）

### 🖥 画面取込オーバーレイ

操作エリアの **画** ボタン、または **⚙ → 表示・記録 → 画面を取り込んで字幕を重ねる** から開きます。ブラウザの選択画面でPDF、PowerPoint、Teams／Zoom、ブラウザ資料などのタブ・ウィンドウ・画面を選ぶと、その映像をDuo内に表示し、端へコメント形式の字幕を重ねます。

- 字幕レールは **右／左／下／自由配置**。字幕欄自体をドラッグして移動できます
- A/B別の訳文色・原文色、文字／背景透明度、文字サイズ、行間、最大幅を変更できます
- 表示件数と保持時間を設定し、古い字幕は上から消えます
- 影、縁取り、角丸を個別にON/OFFできます
- 全画面表示に対応し、共有元の終了や音声Trackの有無を画面上と診断ログへ表示します
- **取込切替**で共有対象を選び直せます。STT実行中は新しい共有音声Trackへ再接続します
- 対応Chromeでブラウザタブを取り込んだ場合だけ、**元タブ操作**でホイールを転送できます
- 注釈は映像との合成PNG、または再編集用JSONとして保存・読込できます
- 画面・音声そのものは表示中だけ保持し、自動録画・自動保存はしません

音声TrackをWeb Speechへ直接渡す機能、VB-CABLE／外部STT APIの並列選択UI、自分向け／相手向けTTSの出力先分離にも対応しています。共有音声が無い場合も勝手にマイクへ切り替えません。

> iPhone／iPadは画面取込の対象外です。通常の通訳画面は従来どおり利用できます。取り込んだ映像は表示であり、外部アプリ自体をDuo上からクリック操作することはできません。

### 音声

**音声認識（STT）**

| 方式 備考                    |                                                               |
| ------------------------ | ------------------------------------------------------------- |
| 🆓 ブラウザ内蔵 Web Speech API | 無料・低遅延。Chrome / Edge 系、マイク入力のみ。AUTO切替は使えません                   |
| ⚡ リアルタイム同時通訳             | OpenAI `gpt-realtime-translate`。訳す方向はA→B／B→A／両方向の3択。1接続につき1方向（両方向は2接続・料金2倍）       |
| OpenAI                   | `gpt-4o-transcribe` / `whisper-1`                             |
| xAI Grok                 | 25言語。モデル選択は不要。キーは翻訳側の xAI と共通。**中国語は非対応**（言語指定を送らず自動判定にまかせます） |
| Groq Whisper             | 高速・安価                                                         |
| Google Gemini            | 音声理解                                                          |

**読み上げ（TTS）**：なし / 🆓 ブラウザ内蔵音声 / OpenAI音声 / xAI Grok Voice（多言語） / 🫛 VOICEVOX WEB版 / ElevenLabs（自分の声・多言語） / Aivis Cloud API / 🖥 ローカルエンジン。選んだエンジンに関係する設定だけが表示されます。ブラウザ内蔵音声では話速・声の高さ・音量、OpenAI音声では13種類の声、モデル、話速、感情、抑揚、緩急、文中の間、音量、追加の話し方、PCMストリーミング、xAIでは話速・感情・抑揚・緩急・文中の間・音量を設定できます。読み上げ対象は「両方」「相手(B)だけ（推奨）」「自分(A)だけ」から選べます。「両方」のときは、自分(A)と相手(B)で別の声を割り当てられます。

`gpt-realtime-translate`だけは例外です。これは音声入力から翻訳音声と字幕を直接返すSpeech-to-Speechモデルなので、別のTTSで訳文を読み上げる必要がありません。リアルタイム同時通訳を選ぶと外部TTS設定は非表示になり、翻訳音声はWebRTC経由で自動再生されます。外部TTSの読み上げ方式・対象・声・原文読み上げ・出力先設定は適用されません。

**音声入力元**：マイクのほか、PCのChrome / Edge では**タブ音声**を取り込めます（オンライン会議の相手の声を直接拾う用途）。

**話し方保持［実験］**：ON時だけ、STTと並列にPitch / Energy / Pause / Speech Rateを解析します。ブラウザ標準TTSとAivisでは発話全体の速度・音量・抑揚傾向へ反映します。VOICEVOX WEB版v3では話速だけを端末側で反映し、声高・抑揚は解析のみです。折りたたみの「話し方解析の状態」で、現在のTTSが反映対象か確認できます。数値の詳細は診断ログの `Prosody Analysis` と `tts prosody-map` に出力されます。

### 用語集

原語 → 訳語 の対応表。CSV（`source,target,note`／UTF-8 BOM付き）で読み書きできます。

同じタブから、**設定・用語集を埋め込んだHTMLを書き出す**こともできます。書き出したファイルを配れば、相手のPCでも同じ用語集で動きます。

### 表示・記録

文字サイズ、パネルの回転・入れ替え、認識途中の文字の表示、**A/Bのスクロール連動**、表示名の変更、ログのダウンロード、診断ログの出力、AI議事録の生成。

## 無料で使う / APIを使う

### 完全無料の組み合わせ

- 翻訳プロバイダ = **無料モード**
- 音声認識 = **ブラウザ内蔵 Web Speech API**
- 読み上げ = **ブラウザ内蔵音声**

APIキー不要・課金なし。ただし Chrome / Edge・マイク入力のみで、用語集とコンテキストは効きません。

### APIを使うと良くなること

- 用語集・会議の背景が翻訳に反映される
- 訳文の精度と自然さが上がる
- 音声認識が Safari / iPhone でも安定して動く
- AUTO（A/B自動交互）が使える
- カメラ翻訳・AI議事録が使える

APIキーは各社のコンソールで取得して、⚙ → 翻訳・API に貼り付けてください。

## プライバシーとAPIキーの扱い

- **サーバーはありません。** すべてブラウザ内で動きます。会話ログが開発者に送られることはありません
- 翻訳・音声認識・読み上げは、**選んだプロバイダのAPI**に直接送信されます。何をどこに送るかは、選んだプロバイダで決まります
- APIキーは端末の `localStorage` に保存されます（「キーを記憶する」がONのとき）。共用PCではOFFにしてください
- カメラ翻訳は**写真を保存しません**。1コマをメモリ上で切り出して送るだけです
- 診断ログはAPIキーを自動で伏せ字にしますが、**会話内容は含まれます**。共有前に中身を確認してください

> ### ⚠️ HTMLの書き出しについて
>
> 「APIキーも埋め込む」をONにして書き出したHTMLには、**APIキーが平文で含まれます。**
> このファイルを公開リポジトリにコミットしたり、他人に渡したりしないでください。配布用のファイルは必ずOFFのまま書き出してください。

## 困ったときは

**音声認識が始まらない / すぐ止まる**

- マイクの許可を確認してください（アドレスバー左の 🔒 → マイク → 許可）
- `https://` のURLか `localhost` である必要があります。HTMLファイルを直接開いた（`file://`）状態ではマイクを使えません
- iPhone / iPad で無料モードが動かない場合は、音声認識をAPIに切り替えるか、PCのChromeでお試しください

**翻訳が失敗する**

- 無料モードは非公式エンドポイントのため、混雑時に失敗することがあります（自動でMyMemoryに切り替わります）
- APIモードで「モデル名が正しくない」と出る場合は、モデル欄の **🔄 更新** を押して選び直してください

**読み上げが鳴らない**

- 端末がサイレントモードになっていないか確認してください
- iOSは「一度画面をタップしてから」でないと音が出ない仕様です。開始ボタンを押した後にもう一度画面をタップしてみてください

**周りの人の声を拾ってしまう**

- 指向性のある外付けマイク（ピンマイクなど）を使うと大きく改善します。ソフト側の設定では解決できない部分です

**それでも直らないとき**

- ⚙ → 表示・記録 → 🩺 診断ログ の「コピー」または「ファイルDL」で出力したものを、Issue に貼り付けてください。環境・設定・動作の記録がまとまっています（**会話内容が含まれるので、貼る前に中身を確認してください**）
