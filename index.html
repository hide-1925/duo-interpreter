キャラ（モデル）
よく使うキャラは名前で選べます。「↗」でそのモデルの AivisHub ページを開けます。
「その他のキャラを表示」を押すと、同じプルダウンへ「にせ」以降の候補を追加します。 一覧に無いモデル（自分で作ったモデルを含む）は「── その他（モデル UUID を貼り付け）──」を選ぶと入力欄が出ます。 貼り付けるのは AivisHub のモデルページ →「詳細情報」→「モデル UUID」の値です。 同じ画面の「話者 UUID」ではありません（モデルページのURL末尾と同じ値です）。
キャラ名の欄は覚えておくための目印で、読み上げの動作には影響しません。 AivisHub から自動で取りにいきますが、AivisHub はブラウザからの読み取りを自分のサイト以外に許していないため、多くの場合は自動で入りません。 その場合はご自分で書いてください。UUID ごとに覚えるので、貼り替えて戻せば名前も戻ります。
スタイル (Style ID)
話し方の調整
キーは Aivis Cloud API ダッシュボード で取得できます（登録時に無料クレジット付き・その後は従量課金または月額）。 モデルUUIDは AivisHub の各モデルのページからコピーして貼り付けてください。初期値は「まお」です。 日本語の読み上げだけがこの声になり、それ以外の言語はブラウザ内蔵音声で読み上げます。 失敗した場合もブラウザ内蔵音声に自動で切り替わります。
自分の声を使う：Style-Bert-VITS2 で作ったモデルを AIVM Generator で変換し、 Aivis Cloud のダッシュボードにアップロードすると、そのモデルUUIDをここに貼るだけで使えます（既定は非公開なので社内利用でも安心です）。 推論の重さは声によって変わらないので、自分の声にしても速度は落ちません。
⚠ ただし Aivis は日本語専用です。カスタムモデルを作っても英語は出せません（エンジン側の仕様）。 自分の声で英語を話したい場合は、上の ElevenLabs をお使いください。
スタイル：モデルによっては「ノーマル／Calm／Shout」等の演じ分けを持っています。モデル UUID を入れて「🔄 スタイル取得」を押してください。 AivisHub 側の都合でスタイル名が読めない場合は、そのまま使える番号を自動で割り出します（並び順は AivisHub のスタイル欄と同じです）。 A席とB席で違うスタイルにすると、1つのモデルのままでも話者を聞き分けられます。 通訳用途では落ち着いた系（ノーマル／Calm）が聞きやすく、Shout や Surprise は向きません。
話し方の調整：既定のままなら Aivis 側に何も送らないので、触らなければ音は変わりません。
・話速 … 読み上げが会話に遅れがちなときは1.1〜1.2倍で詰められます。上げすぎると聞き取りにくくなります
・感情表現 … 選んだスタイルの効き具合。0に近いと平坦に、2に近いと大げさになります。通訳では1.0前後が無難です
・テンポの緩急 … 話す速さの揺れ。上げると抑揚がつき、下げると一定のペースになります
・音量 … 仮想オーディオケーブル経由で相手に小さく聞こえるときに上げます
・改行時の無音 … 文の区切りで空ける間。通訳は1文ずつ読むので、短くしても影響はほとんどありません
・ユーザー辞書UUID … 社名や製品名の読み方を直したいときに使います。辞書は Aivis 側で先に作っておく必要があります
ストリーミング再生：音声が全部でき上がるのを待たず、届いた先頭から鳴らし始めます。長い文ほど鳴り出しが早くなります（公称0.3秒）。 ただし回線が細いと途中で音が途切れることがあります。途切れるようなら切ってください（切ると従来どおり、全部揃ってから鳴らします）。 前の読み上げがまだ鳴っているときは、重ならないよう自動的に従来方式に切り替わります。
接続先
PCで動かしている AivisSpeech（既定 http://127.0.0.1:10101）や VOICEVOX（既定 http://127.0.0.1:50021）に接続します。API互換なのでどちらでも動きます。無料・回数制限なしです。
