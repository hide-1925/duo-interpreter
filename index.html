⚡ リアルタイム同時通訳モード
音声を送りながら訳した音声と字幕が同時に返ってくる方式です（WebRTC接続）。 「録音→文字起こし→翻訳」の順番待ちが無くなるため、遅延が大幅に減り、話し終わるのを待たずに訳が出ます。

・話し手の言語は自動判別されるので、手動/AUTOの切り替えは不要です
・訳文の音声は自動で読み上げられます（TTS設定は使いません）
・翻訳プロバイダの設定（モデル・用語集・背景）は使われません
・料金は音声1分あたり $0.034 程度（従量課金）
・OpenAI の APIキーが必要です（⚙→翻訳・API で OpenAI を選び、キーを入力）
このモードは1接続につき1方向です。双方向にしたい場合は「両方向（2接続）」を選んでください（料金は2倍になります）。
対面で使う：A・B とも「マイク」。1本のマイクで両言語を交互に待ち受けます。

Zoom / Teams で使う：A =「マイク」（自分）、B =「タブ／システム音声」（相手）。開始時に画面共有ダイアログが出るので、会議のタブ（またはウィンドウ／画面全体）を選び「タブの音声も共有」を必ずONにしてください。映像は使わず音声だけを利用します。

「原文をそのまま読み上げる」は翻訳を待たずに発話するので、ボイスチェンジャーのように使えます。 自分の声をずんだもんにするなら、読み上げ＝VOICEVOX／読み上げ対象＝自分(A)の発言だけ／原文読み上げ＝ON の組み合わせです。 （会話ログの翻訳表示はこれまで通り出ます。リアルタイム同時通訳モードは音声がAPI側から返るため対象外です。）
自分の声で読み上げたい場合はこれです。 ElevenLabs の Voice Lab で Instant Voice Cloning を選び、2分未満の自分の録音をアップロードすると、すぐに自分の声が作れます（学習の待ち時間はありません）。 作った声は「🔄 声を取得」で一覧に出てきます。

本人の同意なく他人の声を複製することは規約でも法令でも認められません。自分の声、または許諾を得た声だけをお使いください。

キーは Aivis Cloud API ダッシュボード で取得できます（登録時に無料クレジット付き・その後は従量課金または月額）。 モデルUUIDは AivisHub の各モデルのページからコピーして貼り付けてください。初期値は「Anneli」です。 日本語の読み上げだけがこの声になり、それ以外の言語はブラウザ内蔵音声で読み上げます。 失敗した場合もブラウザ内蔵音声に自動で切り替わります。
自分の声を使う：Style-Bert-VITS2 で作ったモデルを AIVM Generator で変換し、 Aivis Cloud のダッシュボードにアップロードすると、そのモデルUUIDをここに貼るだけで使えます（既定は非公開なので社内利用でも安心です）。 推論の重さは声によって変わらないので、自分の声にしても速度は落ちません。
⚠ ただし Aivis は日本語専用です。カスタムモデルを作っても英語は出せません（エンジン側の仕様）。 自分の声で英語を話したい場合は、上の ElevenLabs をお使いください。
スタイル：モデルによっては「ノーマル／Calm／Shout」等の演じ分けを持っています。モデルUUIDを入れて「🔄 スタイル取得」を押すと一覧に出ます。 A席とB席で違うスタイルにすると、1つのモデルのままでも話者を聞き分けられます。 通訳用途では落ち着いた系（ノーマル／Calm）が聞きやすく、Shout や Surprise は向きません。
話す速さ：読み上げが会話に遅れがちなときは1.1〜1.2倍にすると詰められます。上げすぎると聞き取りにくくなります。
ストリーミング再生：音声が全部でき上がるのを待たず、届いた先頭から鳴らし始めます。長い文ほど鳴り出しが早くなります（公称0.3秒）。 ただし回線が細いと途中で音が途切れることがあります。途切れるようなら切ってください（切ると従来どおり、全部揃ってから鳴らします）。 前の読み上げがまだ鳴っているときは、重ならないよう自動的に従来方式に切り替わります。
PCで動かしている AivisSpeech（既定 http://127.0.0.1:10101）や VOICEVOX（既定 http://127.0.0.1:50021）に接続します。API互換なのでどちらでも動きます。無料・回数制限なしです。

背景の濃さ
ブラウザの窓そのものは透明になりません。ページの背景を変えるだけなので、実際に作業画面へ重ねるには次のどれかと組み合わせてください。
① Windowsで重ねる（推奨・クロマキー）：背景をマゼンタにして、同梱の overlay-helper.ahk（AutoHotkey v2）を実行し Ctrl+Alt+T。 その色だけがWindows側で抜かれるので、文字は不透明のままくっきり残り、背景は完全に透けます。クリックも下のアプリに通ります。
② OBSのブラウザソース：背景を透明にすると完全に透過します。配信・録画に重ねるならこれ。
③ 窓ごと半透明：背景を透明にして、ウィンドウ透過ツールで窓全体を薄くします。手軽ですが文字も一緒に薄くなります。
Ctrl+Alt+O でもこの表示を切り替えられます（クリック透過中はボタンを押せないため）。 文字には黒い縁取りが付くので、明るい画面に重ねても読めます。操作バーは画面下にマウスを近づけると出てきます。
