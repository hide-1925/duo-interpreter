# LICENSE の決定（owner の決定待ち）

## 現状（F-14）

- `LICENSE` ファイルが無い。GitHub もライセンスを認識していない
- README の末尾に「個人利用・社内利用は自由です。」とだけある

この文言では次が決まっていない。

| 論点 | 現状の文言で分かること |
|---|---|
| 商用利用 | 「社内利用」は自由。それ以外（販売・有償サービスへの組み込み）は不明 |
| 改変 | 不明 |
| 再配布 | 不明（改変版・未改変版とも） |
| サブライセンス | 不明 |
| 保証の否認 | 無い |
| 責任の制限 | 無い |
| 著作権表示の要否 | 無い |

ライセンスの無い公開リポジトリは、法的には「閲覧はできるが、複製・改変・再配布の許諾は無い」扱いになる。README の文言とも食い違う。

## 選択肢

| | 商用 | 改変 | 再配布 | 改変版のソース公開義務 | 特許 | 表示義務 | 向いている場合 |
|---|---|---|---|---|---|---|---|
| MIT | 可 | 可 | 可 | なし | 明示なし | 著作権表示 | 自由に使ってほしい。最も短い |
| Apache-2.0 | 可 | 可 | 可 | なし | 明示の許諾あり | 著作権表示・NOTICE・変更の明示 | 自由に使ってほしいが、特許の扱いも明確にしたい |
| MPL-2.0 | 可 | 可 | 可 | 変更したファイルだけ | 明示の許諾あり | あり | 改善はファイル単位で還元してほしい |
| GPL-3.0 | 可 | 可 | 可 | 派生物全体 | 明示の許諾あり | あり | 派生物も必ずオープンにしてほしい |
| 独自（非商用など） | 条件次第 | 条件次第 | 条件次第 | 条件次第 | — | — | 「個人・社内は自由、販売は不可」を守りたい。**OSI のオープンソースではなくなる** |
| 何も付けない（All rights reserved） | 不可 | 不可 | 不可 | — | — | — | 見せるだけ |

- ブラウザ拡張・単一HTMLのアプリで、依存ライブラリの同梱は無い（外部の API を呼ぶだけ）ので、どれを選んでも依存側のライセンスとの衝突は起きにくい
- README の「個人利用・社内利用は自由」を保つなら MIT / Apache-2.0 がそのまま包含する

## 決まったらやること

1. 選んだライセンスの全文を `LICENSE` に置く（著作権者の表記は owner が指定する。実名を出したくない場合は GitHub のハンドルでよい）
2. README の「ライセンス」節を1行にし、`LICENSE` へリンクする
3. 拡張の zip に `LICENSE` を入れるかを決める（入れるなら `extension/LICENSE`）

**Claude はライセンスを選んでいない。** owner の指定があったときだけ `LICENSE` を追加する。
