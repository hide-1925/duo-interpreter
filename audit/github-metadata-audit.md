## 3. 旧 commit への到達経路（F-05）

| 経路 | force push 後 |
|---|---|
| ブランチ・タグ | 新しい履歴に置き換わる |
| `refs/pull/1..26/head` | **旧 commit を指したまま**（GitHub が管理。利用者は変更・削除できない） |
| PR の「Commits」「Files changed」 | 旧 commit を表示し続ける |
| 旧 SHA を直接指定した URL | 到達できなくなるまで GitHub 側の GC 次第 |
| fork | 0（監査時点） |

同じリポジトリに force push する場合は、GitHub Support に「sensitive data の削除（PR ref と cached views）」を依頼する必要がある。
