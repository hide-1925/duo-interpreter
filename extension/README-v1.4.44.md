# Duo Interpreter 拡張 v1.4.44

HTML 本体 **v1.49.33**（ビルド `20260927-v14933-model-tiers`）と対です。

## 翻訳モデル（OpenAI）の初期表示

翻訳モデルの一覧は、最初は主要なモデルだけを出し、残りは「他◯件のモデルを表示」で開きます。
主要に出すモデルを次のようにしました。

| 系統 | 初期表示に出すもの | 「その他」に回すもの |
|---|---|---|
| 5.6系 | `gpt-5.6-luna`・`gpt-5.6-terra`・`gpt-5.6-sol` | 日付付きの版（例：`gpt-5.6-luna-2026-08-14`）、ほかの 5.6 の版 |
| 6系 | 日付の付かないモデルすべて（例：`gpt-6-luna`・`gpt-6-sol`） | 日付付きの版（例：`gpt-6-luna-2026-09-10`・`-0910`） |

これまでは、名前が `gpt-5.6` で始まるものをすべて主要に出していました。そのため日付付きの版も並び、6系は「その他」に入っていました。

- 6系は、APIキーで取得した一覧にあるものをそのまま出します。新しい名前が増えても、こちらで書き足す必要はありません。
- APIキーを入れる前（内蔵の一覧）に出るのは、5.6系の3つだけです。6系のモデル名は内蔵の一覧に入れていません。
- 選んでいるモデルが「その他」にあるときは、今までどおり全部を開いて表示します。
- 並びは、5.6系の luna → terra → sol、続いて6系を名前順です。

## 確認したこと

`test-model-tiers`（新規・5件）で次のことを確かめました。

- 内蔵の一覧では、初期表示が 5.6系の3つになる
- 取得した一覧では、5.6系の3つと6系の日付なしモデルだけが初期表示に出て、日付付きの版・`gpt-5.6-pro`・`gpt-60-x` は「その他」に回る
- 取得した一覧にも、内蔵の備考（「同時通訳におすすめ」など）が付く
- 日付は `-2026-09-10` の形と `-0613` の形の両方を見分ける
- OpenAI 以外のプロバイダは分けない

**実際の OpenAI のアカウントで、6系のモデルが初期表示に並ぶかは、まだ確かめていません。**
