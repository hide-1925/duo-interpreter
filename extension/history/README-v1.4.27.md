# Duo Interpreter 拡張 v1.4.27

HTML 本体 **v1.49.16**（ビルド `20260924-v14916-assist-hold-and-floor`）と対です。

ご指示の①②を実装しました。**どちらも既定 OFF のままです**（`turnDecisionMode=off`）。

---

## ① `assist` の意味を変えました — **待つ判断だけ採用**

これまで `assist` と `active` は**コード上まったく同じ**でした。見分けていたのは1行だけで、
`boundary()` は `off` と `shadow` しか区別していませんでした。つまり **`assist` を選ぶと
実質 `active`** で、名前から受ける印象より大きな一歩でした。

|選択|動き|
|---|---|
|`assist`|**待つ判断だけ採用。切る位置は Rules のまま**|
|`active`|切る位置も Jev が決める|

### なぜ「待つ側だけ」なのか

実測です。

|ログ|HOLD で反対|もっと後ろで切れ|Rules に同意|**Rules より前で切れ**|
|---|---|---|---|---|
|英語（翻訳ON）24件|**15**|—|9|**0**|
|日本語（翻訳OFF）25件|2|13|10|**0**|

**Jev は一度も「もっと早く切れ」と言っていません。** 価値は待つ側に全部あります。
ならば切る位置は Rules のままにしておくのが最小のリスクです。外したときの被害も
**「少し待つ」だけ**で、`turnFloorMaxWaitMs`（既定3秒）で頭打ちになります。

### 細部

- HOLD、`CONTINUING`、`SELF_REPAIR`、言い直しの気配（`repair_likelihood`）は**そのまま採用**します
- **`provider-confirming` は出しません。** これは「別の位置を採る」ためのヒステリシスで、
  位置を採らない `assist` で待つと、**採らない位置のために遅らせるだけ**になります
- `assist` が捨てた位置は**「適用」に数えません。** 診断が実際より働いているように見えないように

## ② 読み上げ開始にも判断層を使えるようにしました（`safe_to_speak`）

これまで `safe_to_speak` は**毎回聞いて、毎回捨てていました。** `floorHold()` が
`return null` のままだったためです。ここをつなぎました。

**APIの費用は増えません。** この答えは commit のときに同じ1リクエストで既に受け取っています。

### 「重なるか」ではなく「重なってよいか」で分けます

**同時通訳は元の話者に重ねて読むのが普通**で、それは「話者との重なり＝許容」という
**利用者の明示的な選択**です。ですから、

|「話者との重なり」の設定|床|
|---|---|
|**許容（allow）**|**働きません。** 利用者の選択を尊重します|
|避ける（avoid）／自動（auto）|**働きます。** 無音を待つとルールが決めた場面で、無音の秒数より確かな根拠になります|

⚙ → 音声 → 発話交代の判断層 の「**読み上げ開始にも判断層を使う（safe_to_speak）**」で
単独に切れます（既定 ON。ただし判断層が `assist` 以上でなければ動きません）。

### 保持は二重に頭打ちになります

1. **答えの鮮度 2秒。** この答えは commit 時点の音響と待ち行列から出ています。実測では
   commit から再生まで **6〜13秒**あったので、それだけ経っていればもうその場面の話では
   ありません。古い答えは使いません
2. **`turnFloorMaxWaitMs`（既定3秒）。** INV-09。上限で必ず解放します

短いほうが効くので、**実効の保持上限は2秒**です。

### 境目

`safe_to_speak` は noul で、**0.5 は「中くらい」ではなく「判断がつかない」**です。
境目は **0.25** に置き、はっきり「いま鳴らすと遮る」と言ったときだけ保持します。
**confidence では切りません**（noul は confidence を持ちません）。

2つの定数（鮮度2000ms・境目0.25）は**仮値**です。trace が取れたら校正します。

## テスト

**決定的 429 件 + E2E 13 件 = 442 件 全通過。**

`test-turn-decision` を 47 → **62 件**へ。15件を追加しました。

**①について**

- `assist` は位置を動かさず、`active` は動かすこと
- `assist` でも HOLD・CONTINUING・SELF_REPAIR・言い直しは**そのまま待つ**こと
- `assist` は `provider-confirming` を**出さない**こと（`active` は出すこと）
- **捨てた位置を「適用」に数えない**こと

**②について**

- 明確な false で保持し、**理由が `safe-to-speak` になる**こと
- **「許容」では働かない**こと（「避ける」では働くこと）
- **0.5（判断がつかない）で待たない**こと
- **鮮度を過ぎた答えを使わない**こと（2秒の前後で切り替わること）
- 答えが無ければ**推測せず黙る**こと
- 設定単独で切れること、`off` と `shadow` では**タイマーすら回さない**こと
- 上限で必ず解放すること（`speak` / `drop` 両方）
- `boundary()` が答えを部分へ残し、**床が聞き直さない**こと

実ブラウザでも、選択肢の文言・チェックボックスの永続化・床の5通りの挙動を確認しています。
