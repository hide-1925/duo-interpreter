# Duo Interpreter 更新手順

HTML v1.47.0 / Chrome・Edge 拡張 v1.4.0

1. `index.html` を使用中のHTML本体と置き換えて、ページを再読み込みしてください。Web公開版を使う場合はこのHTMLを公開先に反映してください。この作業では公開先へのアップロードは行っていません。
2. `duo-interpreter-chrome.zip` を新しい空フォルダーに展開してください。
3. Chrome / Edge の拡張機能管理画面で、展開した拡張を読み込み直してください。読み込み先を変更する場合は旧版を無効化し、新しいフォルダーを「パッケージ化されていない拡張機能を読み込む」で選択してください。
4. HTML本体・Teams・字幕対象の各タブを再読み込みしてください。Teamsは会議に参加する前の再読み込みが必要です。
5. アドオンの版が v1.4.0、HTMLの版が v1.47.0 であることを確認してください。

## Teamsで使う

Web または Many to Many プリセットを選び、Teams Webのタブを「このタブに字幕表示」で字幕対象にします。音声認識の入力設定も確認してください。参加者名・発話状態を取得できた場合、会話カードの話者名に反映されます。話者名の▼から手動修正できます。

アドオンの「Web会議マイク音声」はTeamsへの音声接続のON/OFFです。接続中はHTMLのスピーカーボタンが次の順に切り替わります。

|表示|Teamsへ送る音声|
|---|---|
|on|TTS音声のみ|
|mix|元マイク + TTS音声|
|off|元マイクのみ。自動TTS停止|

offでも認識・翻訳・話者判定は続きます。onに戻した際、off中の発話をまとめて読み上げません。手動カード読み上げはローカルだけに出力します。

設定 → 音声 →「Web会議への音声送出」で同じモード、mixの音量、他の参加者の翻訳音声の中継を設定できます。既定の中継対象は自分のみです。他の参加者を中継するには明示的に参加者を選びます。同じ会議では原則1台のDuoを中継役にしてください。Teams側のミュートは各モードより優先します。

TTSプロバイダーやAPIキーの設定はモード操作で変更されません。TTS自体が未設定・OFF・未対応出力経路の場合、先に音声設定を確認してください。

## 検証範囲と復帰

ローカル検証済みですが、実Teams会議でのDOM検出・発話タイミング調整・相手側への音声到達は未検証です。詳細は `次期仕様実装状況.md` を参照してください。

問題が出た場合は「Web会議マイク音声」を解除してください。元マイクに戻らない場合はTeamsでマイクを選び直すか、会議タブを再読み込みしてください。今回の変更前のHTML v1.46.4 / 拡張 v1.3.5 は `duo-interpreter-pre-v1470.zip` に保存しています。戻す際もHTMLと拡張を一式で戻して各タブを再読み込みしてください。
