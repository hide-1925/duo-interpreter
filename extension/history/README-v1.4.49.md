## 1. 英語の小数点・略語で文を切らない

v1.49.37 の記録（gpt-live-transcribe・英語の演説）では、文を区切る規則が次の3か所を文の終わりとして確定していました。

| 元の英語 | 切れた所 | 起きたこと |
|---|---|---|
| it'll be 1.5 trillion dollars | `1.` | 「1兆ドルになるでしょう。 1兆5000億ドルです。」と、**数字が変わった** |
| U.S. stock markets have set… | `U.S.` | 「アメリカ」だけが1片になり、続けて「米国株式市場…」 |
| in Washington, D.C., it was… | `D.C.` | 後ろを訳すときに前の文を訳し直し、同じ文が2回読まれた |

区切りの規則は、どれも「数字や略語の後ろの `.` もそこで文が終わる」と扱っていました。STT の文字はまだ届いている途中で、`1.` の後ろの `5` や、`U.S.` の後ろの `stock` はまだ来ていませんでした。

今は次のようにします。

- **U.S.・D.C.・e.g. のような頭字語と、Mr.・Dr. などの敬称**は、後ろに語が続いていれば文の終わりにしない。
- **数字の直後の `.`** と **頭字語・敬称で終わっている所**は、次の文字が来るまで待つ。文字が1.2秒止まったら、そこで文が終わったとみなす（"…in 2024." で話が終わった場合）。
- gpt-live のカードを閉じる判定でも、`D.C.` や `1.` で終わる所は「文が終わった」ではなく通常の待ちにする。
- gpt-4o 系の録音結果でも、頭字語は文の終わりに数えない。録音上限で `1.` の所で切れたら、次の録音結果とつないで `1.5` に戻す。

日本語の「。」には影響しません。

## 2. gpt-4o 系で、話し続けるあいだカードを1枚にまとめる

前は、gpt-4o 系では録音1回ごとにカードを閉じていました。録音は、無音0.9秒か録音上限（既定10秒）で切れます。そのため、文の切れ目で息を継ぐ話し手では、ほぼ1文1枚のカードになっていました。

今は gpt-live と同じ形にしました。**カードの見え方と、翻訳・読み上げの始まりを分けています。**

| | 前 | 今 |
|---|---|---|
| カード | 録音ごと（数秒・1文ほど） | 一人が話し続けるあいだ1枚 |
| 翻訳・読み上げ | 録音ごと | カードの中の文ごと（始まる時刻は前と同じ） |
| 次の録音を待つあいだ | 下に「音声認識を処理中」の仮カードが出る | 出ない。カードに「続きを音声認識中」と出る |

### カードを閉じるとき

- 声が **2秒** 途切れたとき
- **30秒か480字** を超えて、文の切れ目が来たとき。まだ文が終わっていない末尾は、次のカードへ移ります。
- 話し手の席か言語が替わったとき
- もう一方の席など、別のカードが後ろに入ったとき。もう一方のマイクの録音で、まだ文字が無いもの（雑音かもしれない）は数えません。
- 停止したとき

### 翻訳と読み上げが始まるとき（前と同じ）

- 文が終わった部分は、録音結果が届いたらすぐ訳します。
- まだ文が終わっていない末尾は、次の録音を待ちます。声が0.9秒途切れたら、その時点で訳と読み上げに回します。カードは開いたままです。
- 一度訳した部分は、ほかのカードへ動かしません。

逐次読み上げが OFF のときは、カードの確定が翻訳の合図なので、前のまま録音ごとにカードを閉じます。

### 判断層（Jev）との関係

v1.49.37 の記録では、判断層は OFF（送信0回）でした。カードが細かく分かれていた原因は判断層ではなく、録音ごとにカードを閉じる作りでした。gpt-4o 系の経路は判断層を使いません。
