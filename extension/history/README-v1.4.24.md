**接続先の設定を一番下へ下げ、字幕の操作を上に出しました。** 接続先は最初の1回しか触りませんが、字幕の操作は毎回使うためです。

## HTML本体の設定欄

### 音声タブの並び替え

|項目|移動先|理由|
|---|---|---|
|**Web会議への音声送出**|音声タブの先頭 → **読み上げ（TTS）の下**|会議へ送るのは読み上げた音声です。読み上げの設定から離れていると、どちらを触ればいいのか分かりません|
|**マイク感度**|音声タブの末尾 → **「話し方解析の状態」の下**|「どこから発話とみなすか」は読み上げではなく**音声認識**の設定です|

### 読み上げの出力先に「Web会議マイク音声」を足しました

⚙ → 音声 → 読み上げの出力先デバイス に **🎧 Web会議マイク音声（アドオン）** が出ます。

- **アドオンの「Web会議マイク音声」ボタンと同じ状態を指します。** ボタンで接続すると、この欄が自動で「Web会議マイク音声」に変わります
- 未接続のときは**（未接続）と出て選べません**。選ぼうとすると、アドオン側で接続するよう案内します
- **会議へ送るトラックは1本**なので、自分向け・相手向けで**共通の入り切り**です。そう画面にも書いてあります
- **選んでもデバイス指定は消えません。** 会議を切ると、元に選んでいた出力先へ戻ります（この選択は保存しません）

### 判断層のパネル

- **説明文を小さくしました**（本文11px・補足10.5px）。説明が長く、設定欄全体を押し下げていたためです。見出しと入力欄は押しやすさのため据え置きです
- **「判断の経路」の説明を書き直しました。** 旧文は「rules と local は外部へ何も送りません」でしたが、いま実際に必要なこと（**ブラウザから直接は繋がらない・アドオン経由を選ぶ・ポップアップ下部で許可する**）が書いてありませんでした
- **`Local` を選択肢から外しました。** 学習済みの重みを入れて初めて動く経路で、**重みを入れる画面がまだありません。** 選んでも Rules のまま動く「効かない設定」だったので、重みが入っているときだけ出します（経路そのものは残してあるので、保存済みの設定は失われません）
