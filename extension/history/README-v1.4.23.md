## ご質問への回答 — **①と③のハイブリッドにしました。選択式でもあります**

`受入確認手順.md` B-8b の三択（①読まない／②次の発話にまとめる／③そのまま読む）について、
**①と③のハイブリッドを作り、3つから選べるようにしました。**

⚙ → 音声 → **「相づちの読み上げ」**

|選択|動き|
|---|---|
|**全部読む**|従来どおり。**既定はこれです**（設定を触らなければ挙動は変わりません）|
|**つなぎ語だけ読まない**|**①③のハイブリッド。推奨します。** 一覧に載っている語だけ落とし、それ以外は読む|
|一覧＋短い発話も読まない|上に加えて N 文字以下も落とす。**中身のある短文も落ちます**|

**落とすのは音声だけです。** 会話カード・議事録・CSV・診断ログには**必ず残ります。**
カードの **▶ を押せば必ず読みます**（手動再生はこの判定を通りません）。

## なぜ「文字数」ではなく「語」で切るのか

B-8b の①は「文字数と品詞で切る」と書きましたが、**実測ログの短い発話を並べると文字数では
切れません。**

|実測の短い発話|3文字以下で切ると|正しい扱い|
|---|---|---|
|`Hm.`|落ちる|**落として良い**（つなぎ語）|
|`そう。`|落ちる|**落としてはいけない**（「本当？」への答えなら「はい」と同義）|
|`あかんな。`|残る|残す（中身がある）|
|`อึ้ย`|残る|タイ語。一覧が無いので**何も落とさない**|

**4件のうち、文字数だけでは1件しか正しく判定できません。** だから既定の判定は語の一覧です。

## 一覧に**入れていない**語があります（重要）

**「はい」「いいえ」「うん」「そう」「なるほど」「Yes」「No」「yeah」「okay」「right」は
落としません。**

これらは**単独で質問の答えになります。** 落とすと意味が反転することがあり、しかも
**聞き手には落ちたことが分かりません。** 相づちと一語の返事は、語の形では区別できません。
区別できるのは「直前に相手が質問したか」を見たときだけで、それは判断層（Jev）の仕事です。

落としたい場合は、設定の「**読まない語の一覧**」に自分で書いてください。空に戻せば既定に
戻ります。書いた場合は**言語に関係なくその一覧だけ**を使います。

既定の一覧（画面にも出ます。コードの表から書き出しているので表示とずれません）

- **ja** — あ、あー、ああ、あの、あのー、えー、ええと、えーと、えと、おお、おー、んー、うーん、ふーん、ふん、へー、へえ、はあ、ほう、おっと、あれ
- **en** — uh, um, umm, er, erm, ah, oh, hmm, hm, mm, mhm, mm-hmm, uh-huh, oops

表記の違いは同一視します。**大小文字・全角半角・カタカナ／ひらがな・句読点・同じ字の連続**
（`Hmmm.` ＝ `hmm`、`ウーン` ＝ `うーん`、`えーーー` ＝ `えー`）。
ただし**長音符「ー」は語の一部として残します** — 「え？」と「えー」は別の語です
（前者は聞き返し、後者は言いよどみ）。**「え？」は落としません。**

## 訳文だけが短い場合は落としません

`それは違います。` が `Hmm.` と訳された場合、**落としません。** 訳文だけが相づちに見えるのは
**翻訳の失敗（要約・欠落）**であって、発言が無かったわけではありません。
**原文と訳文の両方**が相づちのときだけ落とします。

## 効果

相づち1回は**読み上げの枠を1つ**使います。前回の実測では55秒のセッションで
**12発話のうち4つが5文字以下**で、Aivis の枠（60秒10回）を50秒で使い切っていました。
つなぎ語を落とせば、**その枠が後続の発話に回ります。**

診断の「**相づちの読み上げ**」の行に、いまどの設定か・**このセッションで落とした数**・
一覧が既定か手書きかが出ます。**落とした音声は聞き手には存在しないので、数が見えないと
気付けません。**

## 変えていない約束

- 既定は「全部読む」。**設定を触らなければ v1.49.11 と同一挙動です**
- 判断層（Jev）を off にすれば v1.47.1 と同じ挙動に戻ります（INV-08）
- この機能は**判断層を使いません。** Jev の採否とは独立に使えます

## テスト

**決定的 403 件 + E2E 13 件 = 416 件 全通過。** 新設 `test-backchannel`（23件）。
**検査の重点は「落としてはいけないものを落とさないこと」**です。

- 既定（全部読む）では**何も落とさない**こと、壊れた設定値が `read` として読まれること
- **答えになりうる語**（はい／いいえ／うん／そう／なるほど／Yes／No／yeah／okay／right／sure）
  を落とさないこと。**既定の一覧にそれらが混入していないことも別に検査**しています
- 「え？」「Huh?」を落とさないこと（聞き返しは意味を持ちます）
- 一覧の無い言語（タイ語・韓国語・中国語）では**何も落とさない**こと
- 実測ログの4件それぞれが正しく判定されること
- 訳文だけが相づちのときは落とさないこと
- 文字数の閾値が 0 や 999 でも壊れないこと（1〜20 に丸める）
- **手動再生が落ちないこと**、2つの経路（`speak` と `segPump`）が同じ判定を使っていること
