# Duo Interpreter 拡張 v1.4.25

HTML 本体 **v1.49.14**（ビルド `20260923-v14914-settings-type-scale`）と対です。

## ご指摘のとおりでした

設定画面の文字が揃っていませんでした。**同じ画面の中で 1.4 倍の差**がついていました。

|場所|直前|本来|
|---|---|---|
|「Web会議への音声送出」の説明と項目名|**16px**（ブラウザ既定）|11.5px|
|「発話交代の判断層」の説明と項目名|**16px**（ブラウザ既定）|11.5px|
|`.settings-help` の説明|13px|11.5px|
|`.field small` の説明|11px|11.5px|
|チェックボックスの行（`.switch`）|13.5px|11.5px|
|「逐次読み上げの詳細設定／診断」の見出し|13px|12.5px|

**原因は仕組みの側にありました。** 手書きの markup は `.field > label` などのクラスに
載るので勝手に揃いますが、**JSから注入するパネルは素の `<p>` と `<label>` を使う**ので、
クラスが無いと**ブラウザ既定の16px**で出ます。「Web会議への音声送出」と「発話交代の
判断層」がまさにそれでした。

前の版で私は `#turnDecisionSettings{font-size:…}` と**その場しのぎの数値**を足していました。
それをやると次のパネルでまた別の値が書かれます。**今回はやり方ごと直しました。**

## `設定UI設計指針.md` を追加しました

**文字サイズは3段だけ**にしました。

|段|px|使うところ|
|---|---|---|
|**本文**|**11.5**|読む文字すべて — 区画の見出し、小見出し、説明、注意、チェックボックスの行|
|**操作**|**12.5**|押すもののうちフォーム部品でないもの — 折りたたみの見出し、ボタン、タブ|
|**入力**|**16**|`select` / `input` / `textarea`|

**見出しと本文を大きさでは分けません。** 太さ・色・字間で分けます。大きさで分け始めると
段が増えるからです。例外はドロワーの題名（16px）・説明のピル（10.5px）・会話カード（可変）の3つだけ。

このほか、クラスの語彙・長い説明のたたみ方・JSから注入するパネルの決まり・文言の書き方を
1枚にまとめました。

### 直したときに見つけたこと

**入力欄の `font-size:13.5px` は、どこにも効いていませんでした。** 後ろに書かれた
`font-size:16px`（iOSの自動ズーム防止）に上書きされていたためです。実測したら16pxでした。
**死んだ数値が残っていると、読んだ人はそれが効いていると思います。** 消して、指定を1か所に
まとめました。

## 長い説明をたたみました

判断層のパネルの説明4か所を、**押すと開く形**にしました。

- この機能について（既定はOFF・OFFのあいだの動作）
- 経路の選び方と、つなぎ方（CORS・アドオン経由）
- キーの扱い
- 原文を記録するときの注意

**たたんだ見出しは、もともと自動でたたまれる説明（`.notetog` のピル）と同じ形**にしました。
同じ「説明」に2つの見た目があると、それだけで散らかって見えます。

「Web会議への音声送出」の中継の注意も同じ形でたたみました。

判断層のパネルのボタン4つは素の `<button>` でした。`.btn ghost` に揃えて1行に並べました。

## 検査

**決定的 414 件 + E2E 13 件 = 427 件 全通過。**

新設 `test-settings-style`（6件）。**指針の数値とCSSの一致を検査します。**

- 指針の表に書いた 11.5 / 12.5 / 16 が、実際のCSSの各セレクタと一致すること
- **入力欄の文字サイズの指定が1か所だけ**であること（後勝ちで死ぬ数値を残さない）
- JSが作る `details` に **`panel-form` が付いている**こと（付け忘れると16pxで出ます）
- 設定パネルの **`#id` にフォントサイズが書かれていない**こと
- たたんだ説明の見出しが、自動でたたむ側のピルと**同じ形**であること
- 判断層の長い説明が**たたまれている**こと

**指針を書き換えると検査が落ちます。** 文書とコードが片方だけ変わることはありません。

実ブラウザで測った結果：**ドロワーの `summary` は 12.5px が14個・10.5px が9個のみ、
説明文は 64個すべて 11.5px**。ばらつきは無くなりました。
