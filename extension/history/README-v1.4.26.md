## Jev の APIキーの説明をたたみました

⚙ → 音声 → 発話交代の判断層 → **APIキー** の下にあった長い説明を、
**「このキーについて」**のピルを押すと開く形にしました。

### ただし、全部はたたんでいません

あの1行には**2種類の文**が混ざっていました。

|種類|例|扱い|
|---|---|---|
|**いま何が起きているか**|「**いまアドオンを経由できません。ポップアップから接続してください。**」|**たたまない**|
|経路の仕様の説明|「64k context（state＋最長の質問で32k）」「active では alias を拒否します」|たたむ|

**接続できていないことを隠すと、キーを入れても動かない理由が画面から消えます。**
`設定UI設計指針.md` §3 の「常に見えている必要があるのは、その設定を選ぶために読む必要が
ある文だけ」に従って、**状態は残し、背景だけをたたみました。**

- 状態は `turnDecisionKeyState` として**キー欄のすぐ下**に出ます。言うことが無ければ空です
- 背景は `turnDecisionKeyHelp` の中。**外部へ送らない経路（Rules）では、この折りたたみ
  ごと消えます** — 読むものが無いのに見出しだけ残しません

これで判断層のパネルでたたんだ説明は5か所になりました。
