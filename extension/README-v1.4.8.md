# Duo Interpreter Chrome/Edge 拡張 v1.4.8

HTML v1.47.1 と対で動きます。

## 1. 実機で確認できたこと

Web版Teamsで **on（TTSのみ）/ mix（原音+TTS）/ off（原音のみ）の3モードすべて**が
動作することを確認した。マイクの識別も速くなっている。

これにより、v1.4.4〜v1.4.7 の修正が実環境で裏付けられた。

| 版 | 修正内容 | 実機での裏付け |
| --- | --- | --- |
| v1.4.4 | マイクと受信音声が同居する送信経路の選定 | 送出が成立 |
| v1.4.5 | 多段グラフでマイクの証拠が消える問題 | `mic-in-processed-mix` で選定 |
| v1.4.6 | モード切替の空振り | on/off/mix が切り替わる |
| v1.4.7 | ブリッジのICE収集が接続期限を食う問題 | 接続が速くなった |

## 2. v1.4.8 の変更

接続期限の責任をHTML側へ一本化した。

HTML v1.47.1 で、15秒の期限を **offer送信後** に張るよう変更した（従来は自分の
ICE収集より前に張っていたため、1つの期限が両側の収集を抱えていた）。この結果、
最悪の所要は「自分の収集 最大8秒 + 期限 15秒 = 23秒」になる。

Service Worker側のバックストップは20秒だったため、収集が遅いときに**先に落ちて
しまい**、HTML側の具体的なエラーが出る前に「接続がタイムアウトしました」という
曖昧な方へ倒れる。これを30秒へ広げ、期限はHTML側が持ち、Service Workerは
純粋な保険という役割分担にした。
