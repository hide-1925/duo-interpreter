共有音声の詳細設定・VB-CABLE
          
          
          
通常はマイク・共有音声とも上で選んだSTTを使います。共有音声だけWeb Speechにすると、マイクは選択したSTT、共有音声はブラウザ内蔵の認識になります。Web Speechの共有音声Track入力には対応ブラウザが必要です。

          

            
          

          
VB-CABLEは会議アプリの出力音声を、Duoが読める録音デバイスへ渡す仮想ケーブルです。画面共有で音声を取れない場合に使います。OS側で会議の出力をCABLE Inputへ送り、ここでCABLE Outputを選択します。Duoの読み上げ出力と同じケーブルには戻さないでください。入力の準備と認識ブラウザの対応確認が必要です。

          
        

        
      

      

        対面で2人が1本のマイクを使うときのコツ

        画面中央の 手動 / AUTO を切り替えられます。


        手動（推奨・認識精度が高い）：話す前に「🎧 ◯◯語」ボタン、または自分側のパネルをタップして言語を合わせます。音声認識は常に正しい言語で待ち受けるため、誤認識がぐっと減ります。


        AUTO：約9秒無音が続くともう一方の言語に自動で切り替わります。手を使わずに済みますが、切り替わる前に話し始めると誤認識が起きます。

説明
          
文末優先は句点・言語別の語尾を手がかりに翻訳単位をまとめます。認識文字はそのまま逐次表示します。長文や文末が来ない場合は文字数・待ち時間で区切ります。認識誤りそのものを修正する機能ではありません。

          
安定した部分から翻訳し、発話の区切りで会話カードを確定します。Aivisは句点（。）を基本にまとめ、直近60秒で10回の送信上限に達した場合に待機します。枠が残っていれば前の再生後に次を送信します。同じ声・言語・実際の音声設定の確定部分は最大500文字までまとめます。短文が続いて上限に達すると、Fastでも待ち時間が生じます。途中結果を返さない音声認識では、認識結果の到着後から分割処理します。重なりを避ける設定は再生開始を待ちます。再生中の音声は最後まで読みます。

          
Adaptiveは文字の到着速度・観測した無音区間・待ち音声をもとに区切りを調整します。Aivisのみ話速を最大8%補正します（既存設定との合成後は上限2）。手動の詳細値は優先されます。重なりを自動調整する場合は「自動」を選んでください。

        

        
逐次読み上げの詳細設定
          
          
          
          
          待ち音声が増えても、認識文字の表示・発話確定・翻訳は継続します。Aivisの送信待ちでは同じ声・言語の確定部分をまとめ、原文・訳文は省略しません。

      「その他のキャラを表示」を押すと、同じプルダウンへ「にせ」以降の候補を追加します。

      キャラ名の欄は覚えておくための目印で、読み上げの動作には影響しません。
      AivisHub から自動で取りにいきますが、AivisHub はブラウザからの読み取りを自分のサイト以外に許していないため、多くの場合は自動で入りません。

スタイル (Style ID)

      

        
        
        
      

      
      

        話し方の調整
        
        
        
        
        
        
        
        

          
          
        

      

      

        
        
      

      キーは Aivis Cloud API ダッシュボード で取得できます（登録時に無料クレジット付き・その後は従量課金または月額）。
      モデルUUIDは AivisHub の各モデルのページからコピーして貼り付けてください。初期値は「まお」です。
      日本語の読み上げだけがこの声になり、それ以外の言語はブラウザ内蔵音声で読み上げます。
      失敗した場合もブラウザ内蔵音声に自動で切り替わります。

      自分の声を使う：Style-Bert-VITS2 で作ったモデルを
      AIVM Generator で変換し、
      Aivis Cloud のダッシュボードにアップロードすると、そのモデルUUIDをここに貼るだけで使えます（既定は非公開なので社内利用でも安心です）。
      推論の重さは声によって変わらないので、自分の声にしても速度は落ちません。

      ⚠ ただし Aivis は日本語専用です。カスタムモデルを作っても英語は出せません（エンジン側の仕様）。
      自分の声で英語を話したい場合は、上の ElevenLabs をお使いください。

      スタイル：モデルによっては「ノーマル／Calm／Shout」等の演じ分けを持っています。モデル UUID を入れて「🔄 スタイル取得」を押してください。
      AivisHub 側の都合でスタイル名が読めない場合は、そのまま使える番号を自動で割り出します（並び順は AivisHub のスタイル欄と同じです）。
      A席とB席で違うスタイルにすると、1つのモデルのままでも話者を聞き分けられます。
      通訳用途では落ち着いた系（ノーマル／Calm）が聞きやすく、Shout や Surprise は向きません。

      話し方の調整：既定のままなら Aivis 側に何も送らないので、触らなければ音は変わりません。

      ・話速 … 読み上げが会話に遅れがちなときは1.1〜1.2倍で詰められます。上げすぎると聞き取りにくくなります

      ・感情表現 … 選んだスタイルの効き具合。0に近いと平坦に、2に近いと大げさになります。通訳では1.0前後が無難です

      ・テンポの緩急 … 話す速さの揺れ。上げると抑揚がつき、下げると一定のペースになります

      ・音量 … 仮想オーディオケーブル経由で相手に小さく聞こえるときに上げます

      ・改行時の無音 … 文の区切りで空ける間。通訳は1文ずつ読むので、短くしても影響はほとんどありません

      ・ユーザー辞書UUID … 社名や製品名の読み方を直したいときに使います。辞書は Aivis 側で先に作っておく必要があります

      ストリーミング再生：音声が全部でき上がるのを待たず、届いた先頭から鳴らし始めます。長い文ほど鳴り出しが早くなります（公称0.3秒）。
      ただし回線が細いと途中で音が途切れることがあります。途切れるようなら切ってください（切ると従来どおり、全部揃ってから鳴らします）。
      前の読み上げがまだ鳴っているときは、重ならないよう自動的に従来方式に切り替わります。

        話し方の調整
        
        
        
        

          
          
        

      

      キャラとスタイルは、VOICEVOX WEB版APIが公開する一覧を起動時に取得します。取得できない場合も内蔵の網羅リストを表示します。

      キーは su-shiki.com/api/ で無料取得できます（有志が運営する非公式APIです）。
      日本語の読み上げだけがこの声になり、それ以外の言語はブラウザ内蔵音声で読み上げます。
      現行v3 APIでは合成時の声高・抑揚指定がないため、話速だけを端末側の再生速度で反映します。声の高さ・抑揚は解析・診断用として保持します。
      話し方保持をONにすると、元音声の話速を発話ごとに自動補正します（設定欄の値自体は変わりません）。
      ポイント制の1日上限があり、混雑時は失敗することがあります（失敗時はブラウザ内蔵音声に自動で切り替わります）。
      個人利用向けのAPIなので、業務での常用には向きません。
      

    


    

      
      
      API音声認識のとき、どのくらいの音量から発話とみなすか。周囲がうるさい場合は右へ。

説明
        
画面取込＆字幕表示：PDF・PowerPoint・Teams・Zoom・ブラウザ資料などをDuo内へ取り込み、画面端に字幕を表示します。取込映像の拡大・移動・注釈、取込元の切替、注釈のPNG／JSON保存が使えます。対応するブラウザタブではホイール操作も転送できます。外部アプリ自体の操作は元のウィンドウで行います。

        
字幕を別窓表示：別タブの動画や資料を操作しながら、最前面の字幕窓を表示できます。タイトルバーで移動できます。Duo本体は開いたままにしてください。字幕窓を閉じても認識は続きます。

        
音声入力は現在の設定を使います。画面取込の音声で認識中は、取込を終了せずに字幕窓を開いてください。字幕窓の背景は背後のページを透過しません。別窓表示には対応するPCブラウザが必要です。iPhone／iPadでは通常表示をご利用ください。

      

    


    

      
      画面取込オーバーレイと字幕小窓の文字・色・行間・保持時間に共通の設定です。変更は自動保存されます。配置・レール幅・高さ・取込設定は画面取込用です。
      

        
        
        
        
        
        
        
        
        
        
        
        
        
        
      

      

      「保持時間」を「消さない」にすると、表示件数を超えた古い字幕だけが入れ替わります。取込解像度と取込音声は次回の画面取込から反映されます。
      

    


    


    

      
      

        
        
      

      
      

        
        
      

      環境・設定・使用中のマイク・動作の記録・会話ログをまとめて出力します。不具合の原因調査用です。
      そのまま Claude に貼り付けてください。APIキーは自動で伏せ字にしますが、会話内容が含まれるため共有前にご確認ください。
      
      AIプロバイダ選択時に利用できます。確定した部分の最新原文と対応する訳を使います。認識を停止すると、停止時点の本文も含められます。
